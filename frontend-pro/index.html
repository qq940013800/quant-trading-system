🎯 系统本质：我们赚的是什么钱？

从第一性原理出发，价格 = 信息 + 流动性 + 噪声。 QuantDinger 不预测未来，而是应对不确定性——通过系统化的决策流程， 在概率上获得正期望值，并用严格的风控控制尾部风险。

行为偏差 Alpha
处置效应、羊群效应、锚定偏差——人性不变，收割永恒。趋势跟踪、反转策略都属此类。
统计偏差 Alpha
价格的均值回归特性、波动率聚集、相关性结构——从数据中提取微弱但稳定的统计规律。
结构红利 Alpha
流动性溢价、指数再平衡、期权波动率曲面——市场规则创造的结构性机会。

⚖️ 三条不可协商的不变量

这是系统的宪法，任何代码改动都不得违反。

1
因果单向（Causality）
任何计算只能使用 available_at ≤ bar.close 的数据。
前视偏差是量化交易第一大死法。我们在数据管道、特征工程、信号生成每一层都设置前视守卫。
2
决策可审计（Auditability）
每笔接受/拒绝的交易，都能还原当时的输入、模型判断、风控决策。
我们记录完整的决策审计日志——不是为了追责，是为了从错误中学习。系统越用越聪明。
3
阈值来自分布（Distribution-driven）
止损、仓位、信号阈值——全部从历史数据分布中推导，不由绩效网格搜索产生。
过拟合防御是系统第一优先级：PBO + CPCV + Deflated Sharpe Ratio 三重验证缺一不可。
