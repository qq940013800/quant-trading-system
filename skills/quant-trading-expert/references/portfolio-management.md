## 为什么组合管理比选策略更重要

### 数学原理

单个策略的最优不等于组合的最优。

**例子：**
- 策略A：年化15%，最大回撤15%，Sharpe 1.5
- 策略B：年化12%，最大回撤10%，Sharpe 1.8

单独看B更好。但如果A和B的相关性是0.3：

组合（各50%）：
- 年化 = 13.5%
- 最大回撤 ≈ 10%（不是简单平均）
- Sharpe ≈ 2.0（比单独任何一个都高）

**结论：不相关的组合能提高Sharpe，降低回撤——这就是免费的午餐。**

## 相关性矩阵与分散化

### 关键原则

分散化不是"持有很多策略"，而是"持有不相关的策略"。

### 相关性矩阵

| 策略 | 趋势跟踪 | 均值回归 | 套利 | 做市 |
|------|---------|---------|------|------|
| 趋势跟踪 | 1.0 | -0.2 | 0.1 | 0.0 |
| 均值回归 | -0.2 | 1.0 | 0.2 | 0.1 |
| 套利 | 0.1 | 0.2 | 1.0 | 0.3 |
| 做市 | 0.0 | 0.1 | 0.3 | 1.0 |

### 伪分散化陷阱

❌ 持有5个趋势跟踪策略 = 不分散（同一个风险因子）
❌ 持有股票+股票型基金 = 不分散（底层资产重叠）
❌ 用不同指标但同一逻辑 = 不分散

✅ 跨策略类型：趋势 + 均值回归 + 套利 + 做市
✅ 跨资产类别：股票 + 债券 + 商品 + 外汇
✅ 跨时间尺度：高频 + 中频 + 低频

## 风险平价

### 核心理念

不是按资金比例分配，而是按**风险贡献**分配。

**传统60/40组合的问题：**
- 60%股票 + 40%债券
- 但股票波动率是债券的4倍
- 结果：组合90%的风险来自股票——根本不是60/40

### 风险平价的做法

让每个策略对组合的风险贡献相等：

```
组合波动率 = √(Σ w_i² σ_i² + 2 ΣΣ w_i w_j σ_i σ_j ρ_ij)

风险贡献_i = w_i × ∂(组合波动率) / ∂(w_i)

目标：让所有策略的风险贡献相等
```

**结果：** 不管策略本身的波动率是多少，每个策略对组合的风险影响是一样的。

### 实战修正

风险平价在危机时会失效——因为相关性会趋近于1（大家一起跌）。

修正：
1. 加杠杆给低波动资产（债券）
2. 做波动率目标化（组合波动率固定在10%）
3. 加尾部风险对冲

## 动态资金分配

### 问题

策略的表现会变化——有的策略进入上升期，有的进入衰退期。

固定资金比例 = 钱永远分给表现差的策略。

### 动态分配方法

#### 1. 基于表现的分配

```
权重_i ∝ Sharpe_i^k
```

- k=0：等权（不看表现）
- k=1：按Sharpe线性分配
- k=2：按Sharpe平方分配（更激进）

**关键：** 不能太激进，否则会追涨杀跌。

#### 2. 波动率目标化

每个策略的风险预算固定：
```
仓位_i = 目标波动率 / 策略_i的波动率
```

策略波动大时自动减仓，波动小时自动加仓。

#### 3. 多臂老虎机

根据历史表现动态调整，但保留探索空间——给新策略一些机会，防止永远只投老策略。

## 多策略再平衡

### 为什么要再平衡

随着时间推移，表现好的策略占比会越来越大，偏离目标权重。

**例子：**
- 目标：A=50%, B=50%
- 一年后：A涨了50%，B涨了10%
- 实际：A=55%, B=45%

再不平衡，风险敞口就变了。

### 再平衡频率

| 频率 | 优点 | 缺点 |
|------|------|------|
| 每周 | 精准 | 交易成本高 |
| 每月 | 平衡 | 可能滞后 |
| 每季度 | 成本低 | 反应慢 |
| 阈值触发 | 最合理 | 实现复杂 |

**推荐：阈值触发**——偏离目标权重超过5%才再平衡。

## 组合层面的回撤控制

### 组合回撤不是单个策略回撤的简单平均

由于不相关性，组合回撤通常小于最大的单个策略回撤。

但在危机时：
- 相关性趋近于1
- 所有策略一起跌
- 组合回撤 = 最差策略的回撤

### 组合层面的熔断机制

1. **单日回撤限制**：组合单日亏2% → 减仓50%
2. **周度回撤限制**：一周亏5% → 暂停交易
3. **月度回撤限制**：一个月亏10% → 全面复盘

## 常见陷阱

### 1. 过度分散化

策略太多，每个策略资金太少，赚的钱还不够付手续费。

**经验法则：** 3-5个不相关的策略就够了。

### 2. 伪分散化

看起来有5个策略，其实都是同一个逻辑的变体。

**检查方法：** 算相关性矩阵，找相关性>0.7的策略对。

### 3. 危机相关性飙升

平时不相关的策略，危机时一起跌。

**应对：** 压力测试要包含极端情况（2008、2020疫情）。

### 4. 再平衡太频繁

交易成本吃掉收益。

**应对：** 用阈值触发，不是定期再平衡。
