## 第一性原理

### 市场为什么有结构？

**因为交易者是有记忆的。**
- 上次在这个位置买过赚了，下次还会买
- 上次在这个位置卖过亏了，下次到这个位置会先跑
- 于是价格在关键位置反复反应，形成了"结构"

### 市场结构的本质

**价格走势 = 一系列高低点的连接。**

```
上升趋势：高点更高 + 低点更高
下降趋势：高点更低 + 低点更低
震荡市：高点不创新高 + 低点不创新低
```

所有技术分析，本质上都是在识别这些高低点的排列规律。

## 市场状态分类与识别

### 三种基本市场状态

```
┌─────────────────────────────────────────┐
│           市场状态三分类                  │
├─────────────┬─────────────┬─────────────┤
│   趋势市    │   震荡市    │   拐点市    │
│  (Trending) │ (Ranging)   │ (Transition)│
├─────────────┼─────────────┼─────────────┤
│ 单边方向    │ 区间来回    │ 剧烈波动    │
│ 顺势赚钱    │ 高抛低吸    │ 容易亏钱    │
│ 趋势策略    │ 均值回归    │ 观望/对冲   │
└─────────────┴─────────────┴─────────────┘
```

### 识别方法 1：结构法（最可靠）

**上升趋势：**
- 最近的高点 > 前高
- 最近的低点 > 前低
- → 高点更高 + 低点更高 = 上升趋势

**下降趋势：**
- 最近的高点 < 前高
- 最近的低点 < 前低
- → 高点更低 + 低点更低 = 下降趋势

**震荡市：**
- 高点不创新高，低点不创新低
- 价格在一个区间内来回
- → 上下边界清晰

### 识别方法 2：指标法（辅助确认）

| 指标 | 趋势市 | 震荡市 |
|------|--------|--------|
| **ADX** | > 25 | < 20 |
| **布林带** | 开口扩大 | 收窄挤压 |
| **ATR** | 较大（趋势明显） | 较小（盘整） |
| **均线排列** | 多头/空头排列 | 均线纠缠 |

### 识别方法 3：成交量法

- **趋势市**：放量上涨/下跌，缩量回调
- **震荡市**：成交量均匀，没有明显方向
- **拐点市**：成交量突然放大，可能是变盘信号

## 市场结构：高低点序列

### 关键概念

| 概念 | 定义 |
|------|------|
| **Swing High** | 波段高点：左右各有 N 根 K 线比它低 |
| **Swing Low** | 波段低点：左右各有 N 根 K 线比它高 |
| **BOS**（结构突破） | 价格突破前高/前低，趋势延续 |
| **CHoCH**（结构转换） | 趋势被打破，可能反转 |

### 上升趋势结构

```
        高点3 (更高)
       /\
      /  \
     /    \    高点2 (更高)
    /      \  /\
   /        \/  \
  /         /    \
 /         /      \
低点1    低点2 (更高)
```

**规则：**
- 高点1 < 高点2 < 高点3
- 低点1 < 低点2 < 低点3
- 回调不破前低 = 趋势健康

### 下降趋势结构

```
低点3 (更低)
  \
   \    低点2 (更低)
    \  /\
     \/  \
     /    \    低点1
    /      \  /
   /        \/
  /         高点2 (更低)
 /         /
高点1    高点3 (更低)
```

**规则：**
- 高点1 > 高点2 > 高点3
- 低点1 > 低点2 > 低点3
- 反弹不过前高 = 趋势健康

### 结构转换（CHoCH）

**上升趋势转下降趋势的信号：**
1. 价格跌破前一个波段低点
2. 反弹不过前高
3. 再创新低
→ 结构转换完成，趋势可能反转

**反过来就是下降转上升。**

## 趋势判断与分类

### 趋势的三个阶段（道氏理论）

```
第一阶段：积累期
  - 聪明钱开始建仓
  - 大多数人还在悲观
  - 底部缓慢抬升

第二阶段：参与期
  - 大众发现趋势，纷纷入场
  - 趋势最明确、最流畅
  - 利润最丰厚的阶段

第三阶段：派发期
  - 所有人都在谈论这个趋势
  - 聪明人开始出货
  - 顶部放量但涨不动
```

### 趋势强度判断

| 强度 | 特征 |
|------|------|
| **强趋势** | 角度陡、回调浅、成交量配合、连续创新高/低 |
| **中等趋势** | 有回调，但不破前高/低，整体方向明确 |
| **弱趋势** | 角度平缓、回调深、经常横盘、可能随时反转 |

### 趋势线画法

**上升趋势线：**
- 连接两个以上的低点
- 角度不要太陡（太陡不可持续）
- 测试次数越多越有效

**下降趋势线：**
- 连接两个以上的高点
- 突破趋势线 = 可能反转信号

### 趋势的常见错误

- ❌ 把短期波动当趋势反转
- ❌ 画趋势线只找两个点（至少 3 个点确认）
- ❌ 趋势已经很陡了还追（容易回调）
- ❌ 把震荡市当趋势做（来回打脸）

## K线形态识别

### 反转形态（出现在趋势末端）

#### 吞没形态（Engulfing）

**看涨吞没：**
- 前一根是阴线，后一根是大阳线
- 阳线实体完全包住阴线实体
- 出现在下跌趋势末端 = 反转信号

**看跌吞没：**
- 反过来，出现在上涨趋势末端

#### Pin Bar（锤子线/射击之星）

**锤子线（底部反转）：**
- 下影线很长（至少是实体的 2 倍）
- 实体很小，在K线上端
- 出现在下跌趋势末端

**射击之星（顶部反转）：**
- 上影线很长
- 实体很小，在K线下端
- 出现在上涨趋势末端

#### 十字星（Doji）

- 开盘价 = 收盘价，实体极小
- 出现在趋势末端 = 犹豫信号，可能变盘
- 单独用不可靠，需要其他确认

### 持续形态（出现在趋势中途）

#### 旗形整理

- 趋势中出现一小段反向倾斜的盘整
- 像一面小旗子
- 突破后继续原趋势

#### 三角整理

- 高点越来越低，低点越来越高
- 区间逐渐收窄
- 突破方向通常是原趋势方向

### K线形态使用原则

1. **位置比形态重要**：同样的形态，出现在顶部和出现在中途意义完全不同
2. **需要确认**：单根K线形态不可靠，等下一根确认
3. **配合成交量**：反转形态伴随放量更可靠
4. **不要过度解读**：90%的K线都是噪音

## 供需区 / 订单块

### 什么是供需区？

**原理：机构大单成交的价格区间。**
- 买方在这个区间大量买入 = 需求区（支撑）
- 卖方在这个区间大量卖出 = 供给区（阻力）

### 需求区识别方法

**看"从哪根K线开始大幅上涨"：**
1. 找到一根大阳线（涨幅 > 平均K线的 2 倍）
2. 这根阳线前面的几根小K线区间 = 需求区
3. 价格回到这个区间，可能反弹

### 供给区识别方法

反过来：
1. 找到一根大阴线
2. 前面的小K线区间 = 供给区
3. 价格回到这个区间，可能回落

### 订单块（Order Block）

**ICT 概念：**
- 机构最后一根反向K线，后面跟着大幅趋势
- 比如：最后一根阴线，后面开始大涨
- 这根阴线 = 看涨订单块

### 供需区有效性判断

| 有效特征 | 无效特征 |
|---------|---------|
| 区间出来后走了很大一波 | 区间出来后波动很小 |
| 第一次回到区间反应大 | 已经被测试过很多次 |
| 区间有明显成交量 | 区间成交量很小 |
| 区间位置在关键位（前高/前低附近） | 区间在中间位置 |

## 价格突破识别

### 真突破 vs 假突破

**这是交易中最常见的难题。**

#### 真突破特征

1. **收盘价突破**：不是盘中碰一下，是收盘站上去
2. **放量突破**：成交量明显放大（> 平均量 1.5 倍）
3. **突破后不回头**：突破后继续往前走，不跌回来
4. **幅度足够**：突破幅度 > 1%（太小不算突破）

#### 假突破特征

1. **盘中突破，收盘回来**：插针式突破
2. **缩量突破**：没有成交量配合
3. **突破后快速回落**：当天就跌回来
4. **刚好在关键位停住**：扫完止损就反转

### 突破确认方法

**方法 1：收盘价确认**
- 不要看盘中价格，等收盘价
- 收盘价站在突破位上方 = 确认

**方法 2：回踩确认**
- 突破后，价格回踩突破位
- 回踩不破 = 确认有效
- 这是更好的入场点

**方法 3：时间确认**
- 连续 2~3 根K线都站在突破位上方
- 不是假突破

### 常见的假突破陷阱

**扫流动性（Liquidity Sweep）：**
- 价格先突破前高，触发多头止损
- 然后反转下跌
- → 这是典型的"扫止损"

**应对方法：**
- 不要在突破的第一根K线就追
- 等确认（收盘 + 回踩）
- 用小仓位试错，设好止损

## 综合判断清单

每次分析行情，按这个顺序过一遍：

### 第一步：大周期结构
- [ ] 大周期是上升趋势、下降趋势还是震荡？
- [ ] 最近的高低点序列是什么样？
- [ ] 有没有结构转换（CHoCH）的迹象？

### 第二步：小周期入场时机
- [ ] 小周期的趋势方向和大周期一致吗？
- [ ] 现在在趋势的哪个阶段？（积累/参与/派发）
- [ ] 有没有到关键的支撑/阻力位？

### 第三步：形态确认
- [ ] 关键位置有没有出现反转/持续形态？
- [ ] K线形态在什么位置？（顶部/底部/中途）
- [ ] 成交量配合吗？

### 第四步：突破还是假突破
- [ ] 如果是突破，是真突破还是假突破？
- [ ] 放量了吗？收盘确认了吗？
- [ ] 有没有回踩确认？

### 第五步：风控
- [ ] 止损放在哪里？（前低/前高/结构位）
- [ ] 盈亏比够吗？（至少 1:2 以上）
- [ ] 仓位和风险偏好匹配吗？
