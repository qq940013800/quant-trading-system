## 仓位 Sizing 的数学

### 核心问题：一笔交易下多大仓位？

这是量化交易中最重要的决策——比选股重要 10 倍。

### 1. Kelly 公式（理论最优）

```
f* = (p × b - q) / b
```

- f*：最优仓位比例
- p：胜率
- q：败率 = 1 - p
- b：盈亏比（平均盈利 / 平均亏损）

### 为什么实战不用全 Kelly

- 全 Kelly 假设你知道精确的胜率和盈亏比——但你不知道，你估计的是有误差的。
- 估计偏一点，全 Kelly 的结果就会差很多，甚至爆仓。
- 全 Kelly 的回撤非常大——心理上很难扛住。

### 实战方案：分数 Kelly

```
实际仓位 = f* / k
```

- k = 2 ~ 4（常用 1/2 Kelly 或 1/4 Kelly）
- 牺牲一点收益，换大幅降低波动和回撤
- 长期复利来看，分数 Kelly 的实际收益可能比全 Kelly 还高（因为不会中途爆仓）

### 2. 波动率目标法（Vol Targeting）

```
仓位 = 目标波动率 / 实际波动率
```

- 波动大的时候自动减仓，波动小的时候自动加仓
- 好处：组合的风险敞口保持稳定
- 顶级机构常用：不管策略怎么样，先把波动率控制在目标范围内

### 3. 风险平价 (Risk Parity)

```
每个资产贡献的风险相等
```

- 不是按资金分配，是按风险分配
- 股票波动大，就少配；债券波动小，就多配
- 好处：不会因为某个资产波动大就主导整个组合

### 4. 单笔风险预算法（最实用）

```
单笔交易最大亏损 = 总资金 × 风险比例
止损距离 = 入场价 - 止损价
仓位 = 单笔最大亏损 / 止损距离
```

- 比如：总资金 100 万，单笔风险 1% = 1 万
- 止损距离是 2%
- 仓位 = 1 万 / 2% = 50 万

**这是最简单也最实用的方法。**

## 止损体系设计

### 止损的本质

止损 = 承认错误 = 控制左尾。

**为什么必须止损？**
因为亏损是复利的敌人：亏 50% 需要赚 100% 才能回本。

### 四类止损方法

#### 1. 固定止损（最基础）
- 入场后设定一个固定的止损价
- 触发就平仓，不犹豫
- 优点：简单、纪律性强
- 缺点：可能被正常波动洗出去

#### 2. ATR 波动止损（推荐）
```
止损距离 = N × ATR
```
- N 通常取 2 ~ 3
- 波动大的时候止损宽，波动小的时候止损窄
- 好处：自适应市场环境，不会在平静市被轻易扫损

#### 3. 时间止损
- 买入后 N 天内没有达到预期收益，就平仓
- 理由：如果逻辑成立，应该很快见效；不见效说明逻辑可能错了
- 适用：短线策略、均值回归策略

#### 4. 跟踪止盈（让利润奔跑）
- 盈利后，止损价跟着价格往上移
- 比如：从最高点回撤 2×ATR 就止盈
- 好处：既保护已有利润，又不限制上行空间

### 止损的纪律

1. **入场前就定好止损**：不要到了亏损的时候再想"要不要等等"。
2. **止损只向盈利方向移动**：只能往上移（做多），不能往下移。
3. **到了就执行**：不要犹豫，不要"再看一会"。
4. **止损后不要立刻反手**：等信号重新出现再说。

## 回撤控制与熔断

### 回撤是最大的敌人

| 回撤幅度 | 回本需要的涨幅 |
|---------|--------------|
| 10% | 11% |
| 20% | 25% |
| 30% | 43% |
| 50% | 100% |
| 70% | 233% |

**结论：控制回撤比追求收益重要得多。**

### 三级回撤控制

#### 一级：预警线（比如回撤 5%）
- 提醒：注意，开始有回撤了
- 动作：检查策略是否正常，有没有异常
- 仓位：不主动减仓，但也不加仓

#### 二级：降仓线（比如回撤 10%）
- 警告：回撤超过阈值了
- 动作：整体仓位降低 50%
- 目的：控制回撤继续扩大

#### 三级：清盘线（比如回撤 15-20%）
- 停止：这个策略不行了
- 动作：全部平仓，暂停交易
- 后续：重新研究、重新验证后才能上线

### 日亏限额

- 单日亏损达到总资金的 X%（比如 2%），当天停止交易
- 理由：人在连续亏损时容易上头，做傻事
- 强制停下来，第二天再看

### 熔断机制的本质

熔断不是预测市场会崩，是**防止你自己崩掉**。

## 风险预算与分散

### 风险预算，不是资金预算

不要问"我给这个策略分配多少钱"，要问"我给这个策略分配多少风险"。

**例子：**
- 策略 A：年化波动 20%，我给它 50% 的资金
- 策略 B：年化波动 10%，我给它 50% 的资金
- 结果：A 贡献了 80% 的组合风险——这不是你想要的

**正确做法：**
- 给每个策略分配相等的风险预算（比如各占 25% 的风险）
- 波动大的策略少配资金，波动小的策略多配资金

### 真正的分散

不是持有多少只股票，而是：

1. **跨策略类型**：趋势跟踪 + 均值回归 + 套利 + 做市
2. **跨时间尺度**：高频 + 中频 + 低频
3. **跨资产类别**：股票 + 债券 + 商品 + 外汇
4. **跨地区**：美股 + A股 + 欧股 + 新兴市场

### 伪分散的陷阱

- ❌ 10 只科技股 = 不分散（同一个风险因子）
- ❌ 5 个趋势跟踪策略 = 不分散（同一个信号源）
- ❌ 股票 + 股票型基金 = 不分散（底层资产重叠）

## 执行算法选择

### 执行的目标

不是"卖个好价钱"，是**最小化总交易成本**：

```
总交易成本 = 买卖价差成本 + 市场冲击成本 + 时机风险成本
```

### 常见执行算法

#### 1. TWAP (Time Weighted Average Price)
- 把大单平均分成很多小单，按时间均匀执行
- 优点：简单、可预测
- 缺点：不考虑市场情况，可能在流动性差的时候交易
- 适用：流动性好的市场、时间不紧迫的交易

#### 2. VWAP (Volume Weighted Average Price)
- 按历史成交量分布来安排下单节奏
- 成交量大的时候多交易，成交量小的时候少交易
- 优点：更贴近市场实际情况
- 缺点：假设今天的成交量分布和历史一样
- 适用：大多数常规交易

#### 3. POV (Percentage of Volume)
- 按当前市场成交量的固定比例参与
- 比如：永远只吃市场成交量的 10%
- 优点：灵活、不会对市场造成太大冲击
- 缺点：市场清淡的时候执行很慢
- 适用：大单、需要隐蔽执行

#### 4. Implementation Shortfall
- 权衡"尽快执行的成本" vs "等待的风险"
- 目标：最小化 决策时价格 和 实际成交价格 的差
- 优点：理论上最优
- 缺点：复杂、需要参数调整
- 适用：机构大单、对成本敏感的交易

#### 5. 自适应算法
- 根据市场情况动态调整：波动大就慢点，流动性好就快点
- 高级版本：用 ML 预测最佳执行时机
- 适用：专业量化机构

### 算法选择决策树

```
交易量大不大？
  ├─ 小（< 1% 日成交量）→ 直接下单就行
  └─ 大 → 紧急吗？
       ├─ 紧急 → 快单（接受较高冲击成本）
       └─ 不紧急 → 慢单（最小化冲击）
            ├─ 流动性好 → TWAP/VWAP
            └─ 流动性差 → POV + 拆得更碎
```

## 市场冲击与滑点建模

### 市场冲击的本质

你下单买的人，本来是卖给别人的。你把他的货买走了，价格就涨了——这就是市场冲击。

### 冲击成本的公式

```
冲击成本 ≈ k × (下单量 / 日成交量)^0.5
```

- k 是常数，和品种有关
- 冲击和下单量的平方根成正比——不是线性的
- 意思是：大单的单位成本更高

### 滑点的来源

1. **买卖价差**：你买在卖价，卖在买价，一来一回就亏了价差
2. **市场冲击**：你的单子推动价格朝不利方向走
3. **时机延迟**：信号产生到下单成交之间，价格变了
4. **流动性蒸发**：真到需要跑的时候，市场上没人接盘

### 实战经验法则

- 小盘股：滑点可能有 0.5% ~ 2%
- 大盘股：滑点 0.1% ~ 0.3%
- 期货主力合约：滑点 1 ~ 2 个 tick
- 急跌/急涨时：滑点可能是平时的 5 ~ 10 倍

### 回测时的滑点假设

**不要太乐观。** 回测里假设 1 个 tick 滑点，实盘可能是 5 个。

建议：
- 保守估计 = 历史平均滑点 × 2
- 极端情况 = 历史最大滑点

## 尾部风险对冲

### 什么是尾部风险

就是黑天鹅——小概率但影响巨大的事件。

### 为什么需要尾部对冲

- 大多数策略在正常市场表现很好
- 但遇到极端行情（2008、2020 年 3 月），可能一天亏掉半年利润
- 尾部对冲 = 买保险——平时花点小钱，出事的时候保命

### 常见对冲工具

1. **虚值看跌期权 (OTM Put)**
   - 买入深度虚值的看跌期权
   - 平时成本很低（权利金）
   - 市场暴跌时，期权价值暴涨，对冲组合损失
   - 缺点：持续的权利金支出，长期是成本

2. **VIX 多头**
   - 买入 VIX 期货或 ETF
   - 市场恐慌时 VIX 飙升
   - 缺点：VIX 长期是向下漂移的，持有成本高

3. **国债多头（避险资产）**
   - 股票跌的时候，国债通常涨
   - 天然的对冲
   - 缺点：相关性不是稳定的，有时候股债双杀

4. **降低杠杆**
   - 最简单的对冲：不那么激进
   - 杠杆低了，爆仓风险就小了

### 对冲的成本思维

尾部对冲不是免费的，它是保险费。

- 如果你是长期投资者，尾部对冲的成本可能侵蚀 1~2% 的年化收益
- 但遇到一次 2008 年级别的危机，它能帮你少亏 20~30%
- 长期来看，这个保险值得买

### 最优对冲比例

没有标准答案，取决于你的风险承受能力。

经验法则：
- 保守型：对冲 30%~50% 的组合风险
- 平衡型：对冲 10%~20%
- 激进型：不对冲，靠止损和分散化

## 风控检查清单

每次上线新策略前，过一遍这个清单：

- [ ] 单笔最大亏损控制在总资金的 1% 以内？
- [ ] 止损位在入场前就定好了？
- [ ] 单日最大亏损限额是多少？触发后会自动停？
- [ ] 最大回撤预警线/降仓线/清盘线分别是多少？
- [ ] 策略之间的相关性有多高？是不是伪分散？
- [ ] 压力测试做了吗？极端行情下会亏多少？
- [ ] 尾部风险有对冲吗？还是纯裸奔？
- [ ] 执行滑点的假设是保守的还是乐观的？
- [ ] 仓位调整规则是什么？会不会在压力下失控？
