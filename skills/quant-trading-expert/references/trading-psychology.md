## 为什么量化也需要心理学

### 误区

"我是量化交易，用模型做决策，不需要心理学吧？"

### 现实

1. **模型是人写的**——写模型的人有偏差，模型就有偏差
2. **参数是人调的**——调参的人有确认偏误，就会过拟合
3. **上线是人决定的**——不敢上、过早停、死扛，都是人性
4. **风控是人设的**——止损太窄、仓位太重，都是恐惧和贪婪
5. **黑天鹅来临时**——模型失效了，最后还是人来救场

**顶级量化机构不只是数学好，更是纪律好、心态稳。**

## 常见行为偏差清单

### 1. 确认偏误（Confirmation Bias）

**表现：** 只看支持自己观点的证据，忽略反对的证据。

**在量化中的表现：**
- 回测只看好看的那段，不好看的那段说"那是异常"
- 策略赚钱了就觉得自己是天才，亏钱了就说是市场不对
- 主动找理由说服自己"这个例外没关系"

**应对：**
- 主动寻找反面证据
- 用逆向思维："怎么做这个策略一定会亏钱？"
- 把策略的缺点和优点写下来，同等重视

### 2. 处置效应（Disposition Effect）

**表现：** 过早卖出盈利的股票，死扛亏损的股票。

**在量化中的表现：**
- 赚一点就想跑（止盈太早）
- 亏了就想"再等等，会回来的"（止损太晚）

**数学本质：**
- 截断亏损，让利润奔跑——这不是口号，是数学
- 左尾截断 + 右尾暴露 = 长期正期望值

### 3. 损失厌恶（Loss Aversion）

**表现：** 亏100块的痛苦，远大于赚100块的快乐。

**在量化中的表现：**
- 因为怕亏，仓位太轻，赚不到钱
- 连续止损几次后，不敢交易了
- 为了"避免损失"，过度交易（频繁止盈止损）

**应对：**
- 用系统代替情绪——仓位由公式算，不是由心情决定
- 接受亏损是交易的一部分——没有策略是100%胜率的
- 看长期期望值，不看单笔盈亏

### 4. 过度自信（Overconfidence）

**表现：** 高估自己的能力，低估风险。

**在量化中的表现：**
- 回测Sharpe 2.0，就觉得实盘也能做到
- 加杠杆，觉得"这次不一样"
- 不做压力测试，觉得"这种事不会发生在我身上"

**应对：**
- 用分数Kelly，不用全Kelly
- 做压力测试，考虑最坏情况
- 留安全边际，不要把仓位卡太满

### 5. 锚定效应（Anchoring）

**表现：** 被第一个看到的数字锚定了。

**在量化中的表现：**
- 觉得"这个股票曾经到过100块，现在50块很便宜"
- 用历史最高点做参照，而不是用当前价值
- 止损设在某个整数位（100、200），而不是基于波动率

**应对：**
- 用ATR做止损，不是用价格整数
- 问自己："如果我现在没有持仓，我会在这个价位买吗？"

### 6. 羊群效应（Herding）

**表现：** 别人都在做，我也跟着做。

**在量化中的表现：**
- 看到别人用某个因子赚钱，自己也用
- 策略太拥挤，收益衰减
- 危机时大家一起跑，流动性枯竭

**应对：**
- 问自己："这个策略为什么有效？我理解它的逻辑吗？"
- 找不拥挤的Alpha
- 分散化，不要把鸡蛋放在一个篮子里

### 7. 近因偏差（Recency Bias）

**表现：** 最近发生的事，权重放得太大。

**在量化中的表现：**
- 策略连续赚了3个月，就觉得它永远会赚
- 策略连续亏了1个月，就觉得它失效了
- 用最近的数据调参，忽略更长的历史

**应对：**
- 用Walk-Forward分析，不是用最近的数据
- 看完整的周期，不是只看最近一段
- 策略表现有波动是正常的，不要一跌就慌

## 策略的"心理"

### 什么是策略的"心理"

策略也有类似人的"心理状态"：
- 什么时候它"自信"（信号强度高）
- 什么时候它"犹豫"（信号强度中等）
- 什么时候它"恐慌"（波动率飙升，信号混乱）
- 什么时候它"疲劳"（市场变了，逻辑失效了）

### 策略的情绪管理

1. **信号强度分级**
   - 强信号（>0.8）：满仓
   - 中等信号（0.5-0.8）：半仓
   - 弱信号（<0.5）：不交易或极轻仓

2. **连续亏损后的"冷静期"**
   - 连续3次止损 → 降低仓位50%
   - 连续5次止损 → 暂停交易，复盘

3. **波动率适应**
   - 波动率低的时候，可以稍微激进一点
   - 波动率高的时候，必须保守

## 执行纪律与系统韧性

### 为什么纪律比聪明重要

- 一个普通但纪律严明的策略，长期能赚钱
- 一个聪明但执行随意的策略，长期会亏钱

### 纪律的核心原则

1. **规则提前定好，交易时不改**
   - 入场条件、止损、止盈，都提前写好
   - 交易时不临时改主意

2. **用系统代替情绪**
   - 仓位由公式算，不是由心情决定
   - 止损自动执行，不是靠人盯着

3. **接受亏损是成本**
   - 止损不是失败，是做生意的成本
   - 就像餐厅要付房租一样，交易要付止损

4. **不报复性交易**
   - 亏了一笔，不要马上想"赢回来"
   - 暂停一下，按规则来

## 团队与决策机制

### 单人交易 vs 团队交易

| 单人交易 | 团队交易 |
|---------|---------|
| 灵活，反应快 | 慢，但更稳健 |
| 自己说了算 | 需要达成共识 |
| 容易有偏差 | 互相制衡 |
| 一个人扛所有 | 分担压力 |

### 顶级机构的决策机制

1. **投资委员会**——重大决策集体讨论
2. **风险委员会**——独立于交易，专门管风险
3. **事前审批**——策略上线前要过审批
4. **事后复盘**——定期复盘，总结经验教训

## 常见陷阱

### 1. 把"感觉"当直觉

"我感觉这个会涨"——这不是直觉，是偏差。

真正的直觉是：长期经验积累的快速模式识别。

### 2. 用结果判断决策质量

- 决策对了但结果不好 = 好决策（运气差）
- 决策错了但结果好 = 坏决策（运气好）

要看过程，不要只看结果。

### 3. 过度拟合自己的心理

- "我能承受10%的回撤"——真到了回撤10%的时候，你可能就崩了
- 压力测试要考虑心理承受力，不只是数学上的
