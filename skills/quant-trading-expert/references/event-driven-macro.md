## 什么是事件驱动交易

### 定义

事件驱动交易：围绕特定的经济事件、公司事件、政策事件进行交易。

### 核心逻辑

```
事件发生 → 市场预期差 → 价格调整 → 交易机会
```

**关键不是事件本身，而是"预期差"——实际结果和市场预期的差距。**

### 例子

- 美联储加息25个基点——如果市场预期是50个基点，那就是利空出尽，涨
- 非农数据超预期——如果市场预期是10万，实际是20万，那就是利好，涨

## 核心事件类型

### 1. 央行决议（最重要）

**事件：** 美联储、欧央行、中国央行等的利率决议、货币政策声明。

**为什么重要：**
- 利率是所有资产定价的锚
- 央行的措辞变化（鹰派/鸽派）会影响整个市场

**关键时间：**
- 美联储FOMC：每年8次，提前公布日期
- 欧洲央行：每月一次
- 中国央行：不定期，MLF/LPR报价

**交易要点：**
- 决议前市场通常会减仓、观望
- 决议公布后波动会瞬间放大
- 重点看声明的措辞变化，不只是利率本身

### 2. 重要经济数据

**核心数据：**

| 数据 | 重要性 | 影响 |
|------|--------|------|
| 非农就业（美国） | ⭐⭐⭐⭐⭐ | 美元、黄金、全球风险情绪 |
| CPI通胀 | ⭐⭐⭐⭐⭐ | 央行政策预期、利率 |
| GDP增长 | ⭐⭐⭐⭐ | 经济基本面 |
| PMI采购经理指数 | ⭐⭐⭐⭐ | 经济领先指标 |
| 零售销售 | ⭐⭐⭐ | 消费强弱 |

**交易要点：**
- 数据公布前，市场会有一致预期
- 实际值 vs 预期值 = 预期差
- 超预期 → 利好/利空（看具体数据）

### 3. 公司事件（股票相关）

- 财报发布
- 并购重组
- 分红拆股
- 高管变动

### 4. 地缘政治事件

- 战争、冲突
- 选举
- 贸易战、制裁
- 重大政策变化

**特点：** 不可预测，影响大，持续时间长。

## 宏观分析框架

### 美林时钟（经济周期四阶段）

```
        增长 ↑
         │
  衰退   │   复苏
  (债券) │   (股票)
         │
─────────┼───────── 通胀 ↑
         │
  滞胀   │   过热
  (现金) │   (商品)
         │
```

**四个阶段：**

1. **复苏期**（增长↑，通胀↓）→ 股票最好
2. **过热期**（增长↑，通胀↑）→ 商品最好
3. **滞胀期**（增长↓，通胀↑）→ 现金最好
4. **衰退期**（增长↓，通胀↓）→ 债券最好

### 利率与汇率的关系

- 利率上升 → 资金流入 → 汇率上升
- 利率下降 → 资金流出 → 汇率下降

### 风险偏好

- 风险偏好高 → 股票、商品、加密货币涨
- 风险偏好低 → 黄金、美债、日元涨（避险）

## 事件交易策略

### 1. 数据公布后的"跳空交易"

**逻辑：** 数据公布后，市场会快速调整，但经常会反应过度，然后回归。

**做法：**
- 数据公布后，如果价格瞬间跳空很大
- 等15-30分钟，看是不是过度反应
- 如果是，做反向交易（回归）

### 2. 央行决议的"先涨后跌"或"先跌后涨"

**逻辑：** 决议公布后，市场第一反应经常是错的，然后才会真正走对方向。

**做法：**
- 不要在公布的瞬间交易
- 等30分钟到1小时，看趋势确认
- 再跟着方向走

### 3. 事件前的"波动率交易"

**逻辑：** 事件前，波动率会很低（市场观望）；事件后，波动率会飙升。

**做法：**
- 事件前买入期权（做多波动率）
- 事件后波动率飙升，赚钱
- 不赌方向，赌波动

### 4. 事件后的趋势延续

**逻辑：** 重要事件会改变市场的长期趋势，不只是短期波动。

**做法：**
- 美联储转鸽 → 做多股票、黄金
- 经济衰退确认 → 做空商品、做多债券

## 事件风险与应对

### 事件风险是什么

**黑天鹅事件：** 不可预测、影响巨大的事件。

例子：
- 2020年疫情爆发
- 2008年金融危机
- 英国脱欧公投

### 怎么应对

1. **事件前减仓**
   - 重大事件（如大选、央行决议）前，降低仓位
   - 不要赌方向

2. **止损必须设好**
   - 事件公布后，价格可能瞬间跳空
   - 止损可能滑点很大

3. **不要重仓赌事件**
   - 事件交易就像买彩票
   - 用小仓位玩，不要all in

4. **分散化**
   - 不要只做一个品种
   - 事件对不同品种的影响不同

## 常见陷阱

### 1. "我知道会发生什么"

事件发生后，每个人都能说出一套道理。但事前，没人知道。

**不要觉得自己能预测事件结果。**

### 2. 过度交易数据公布

数据公布后波动大，看起来机会多。但其实大多是噪声，很难赚钱。

**少动多看。**

### 3. 忽略预期差

重要的不是数据好不好，是数据和预期的差距。

预期内的好数据 = 没行情
超预期的差数据 = 大涨

### 4. 事件后死扛

事件公布后，价格瞬间走了，你的方向反了。不要死扛，先出来再说。

## 思考工具：事件交易检查清单

- [ ] 这个事件市场预期是什么？
- [ ] 如果实际结果和预期一致，会怎么走？
- [ ] 如果超预期，会怎么走？
- [ ] 如果低于预期，会怎么走？
- [ ] 我有没有提前减仓？
- [ ] 我的止损设好了吗？滑点风险考虑了吗？
- [ ] 我是在赌方向，还是在做概率？
