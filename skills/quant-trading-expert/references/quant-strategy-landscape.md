## 统计套利类

### 核心逻辑

统计套利的本质：**市场短期会过度反应，但长期会回归统计均衡。你赚的是"过度反应后的修正"。**

### 配对交易（Pairs Trading）

#### 第一性拆解
- **Alpha 来源**：统计偏差（两个基本面相似的标的，价格偏离了历史均衡关系）
- **操作**：找两个历史高度相关的股票，价差扩大时做多低估的、做空高估的，等价差收敛平仓
- **为什么有效**：短期情绪或资金流导致偏离，但长期来看估值会回归
- **失效条件**：其中一个公司基本面发生变化（不再是"相似公司"）→ 价差不收敛了

#### 关键参数
- 相关性阈值（通常 > 0.85）
- 协整检验（Engle-Granger / Johansen）
- 入场阈值（2 倍标准差）
- 出场阈值（0.5 倍标准差）

### 协整套利

#### 与配对交易的区别
- 配对交易看的是**相关系数**——但相关不等于均衡
- 协整套利看的是**长期均衡关系**（cointegration）——即使短期不相关，长期会收敛
- 协整套利更严谨，也更稳定

### 均值回归（Mean Reversion）

#### 第一性拆解
- **Alpha 来源**：行为偏差（散户追涨杀跌导致短期超涨超跌）
- **操作**：RSI 超买做空、超卖做多；布林带上下轨反向操作
- **为什么有效**：短期价格偏离基本面，但长期会回归
- **失效条件**：强趋势市——超买之后更超买，均值回归策略连续止损

#### 关键提醒
- 均值回归和趋势跟踪是**天敌**——同一个市场环境下，一个赚钱另一个就亏钱
- 组合里同时有这两类策略，天然形成对冲

### 多因子统计套利

#### 第一性拆解
- **Alpha 来源**：行为偏差 + 统计偏差
- **操作**：用几百个因子预测个股未来收益，做多高分股、做空低分股，保持市场中性
- **为什么有效**：单一因子预测力弱，但几百个因子叠加起来，统计上有显著的预测力
- **代表机构**：文艺复兴、D.E. Shaw、Two Sigma

#### 核心难点
1. **过拟合**：因子越多，越容易找到噪声里的伪规律
2. **拥挤**：大家都用类似的因子，收益会衰减
3. **交易成本**：换手率很高，滑点和佣金是大敌

## 套利类（无方向）

### 核心逻辑

**同一资产在不同地方/不同形式下，价格应该一致。不一致就有套利空间。**

这类策略不赌方向，赚的是"市场微观结构的裂缝"。风险低但容量也低。

### ETF 套利

- **原理**：ETF 二级市场价格 和 一篮子成分股的净值（IOPV）不一致
- **操作**：ETF 溢价时，买成分股 → 申赎 ETF → 卖出 ETF
- **风险**：申赎成本、成分股流动性、申赎门槛

### 期现套利

- **原理**：期货价格 和 现货价格（基差）偏离理论值
- **操作**：期货升水时，买现货 + 空期货，等交割收敛
- **风险**：保证金追加、交割规则、持仓成本

### 跨期套利

- **原理**：同一品种不同到期月份的价差偏离历史区间
- **操作**：价差过大时，买近月 + 空远月（或反向）
- **风险**：合约流动性、移仓成本

### 跨市场套利

- **原理**：同一资产在不同交易所价格不一致（比如 A/H 股、伦铜/沪铜）
- **风险**：汇率风险、转移成本、交易制度差异

### 可转债套利

- **原理**：可转债 = 纯债 + 看涨期权。当转债定价偏低时，买入转债 + 做空正股，赚定价回归的钱
- **进阶**：下修博弈、赎回博弈
- **风险**：下修不及预期、流动性、强赎

### 三角套利（外汇 / 加密）

- **原理**：三种货币的交叉汇率不一致，循环兑换无风险套利
- **特点**：速度极快、竞争激烈，基本是高频玩家的游戏

## 做市类

### 核心逻辑

**做市不是预测方向，是"卖即时性"。** 别人急着买/卖，你提供流动性，收买卖价差作为报酬。

### 被动做市

- **操作**：同时挂买单和卖单，赚中间的价差
- **风险**：库存风险——价格单边走，你手里的仓位亏大钱
- **核心能力**：库存管理、风险定价

### 主动做市

- **操作**：根据市场方向和库存，动态调整报价——看多就把买单挂高一点，卖单也挂高一点
- **比被动做市更灵活，但也更考验判断**

### 订单流失套利

- **原理**：预测下一笔大订单是买还是卖，提前抢跑
- **周期**：极短（几秒到几分钟）
- **壁垒**：低延迟、订单簿数据分析能力

### 代表机构

Citadel Securities、Jane Street、Optiver、Susquehanna、Jump Trading。
做市是它们的核心业务，不预测方向，赚的是"提供流动性"的钱。

## 因子投资类

### 核心逻辑

**某些因子长期有超额收益，要么是风险补偿，要么是行为偏差。**

这是慢变量策略——持有期几个月到几年，容量极大。

### 六大经典因子

| 因子 | 逻辑 | 超额收益来源 |
|------|------|------------|
| **价值（Value）** | 买便宜的（低 PE/PB/PS），卖贵的 | 风险补偿 + 行为偏差（投资者过度乐观于成长股） |
| **动量（Momentum）** | 过去涨的未来继续涨 | 行为偏差（信息扩散慢、羊群效应） |
| **质量（Quality）** | 买盈利能力强、财务健康的公司 | 风险补偿 |
| **低波动（Low Volatility）** | 买低波动股票，风险调整后收益更好 | 行为偏差（彩票偏好——大家都想要暴涨股） |
| **规模（Size）** | 小盘股长期跑赢大盘 | 风险补偿（小盘股风险更高） |
| **成长（Growth）** | 买盈利增速快的公司 | 行为偏差（过度外推增长趋势） |

### 代表机构

AQR、Dimensional Fund Advisors、Bridgeway。
因子投资是学术研究最充分的领域，也是最透明的——方法公开，逻辑清晰。

### 失效条件
- **拥挤**：太多人做同样的因子，收益衰减
- ** regime 变化**：某些因子在特定市场环境下长期失效（比如价值因子在 2010 年代跑输）
- **数据挖掘偏差**：论文发表的因子，往往已经被套利掉了

## 事件驱动类

### 核心逻辑

**事件发生后，市场定价不充分。你赚的是"价格修正"的钱。**

### 并购套利（Merger Arbitrage）

- **原理**：并购公告后，目标公司股价通常低于收购价（因为有交易失败的风险）
- **操作**：买入目标公司股票，等并购完成，赚差价
- **收益来源**：交易成功的概率 × 价差 - 交易失败的损失
- **风险**：交易失败、监管不批、股东反对

### 分拆套利（Spin-off Arbitrage）

- **原理**：母公司分拆子公司后，子公司定价往往不合理
- **操作**：买入分拆后的子公司，等价值发现

### 事件交易

- 财报超预期/不及预期前后交易
- IPO 抑价交易
- 指数调样（纳入/剔除指数）前后交易
- 再融资、分红、拆股等事件

## 宏观量化类

### 核心逻辑

**交易的是宏观经济变量——利率、汇率、通胀、增长——的趋势和周期。**

### 宏观趋势

- 跟踪利率、汇率、大宗商品的大周期趋势
- 类似 CTA，但标的是宏观资产
- 代表：Bridgewater、Man AHL

### 套利宏观

- 国家间利差套利
- 通胀差套利
- 增长差套利
- 核心是"全球宏观相对价值"

### 波动率交易

- 卖波动率（做空 VIX 类产品）——赌市场平静
- 买波动率——赌市场恐慌
- 本质是赌波动率的均值回归
- **风险**：尾部风险——一次黑天鹅就能亏掉几年利润

### 全天候策略（All Weather）

- Bridgewater 的经典框架
- 不预测经济环境，而是构建一个在任何经济环境下都不崩的组合
- 核心：风险平价 + 跨资产分散

## 高频 / 低延迟类

### 核心逻辑

**在高频领域，速度就是一切。快 1 毫秒就是生死。**

### 延迟套利

- 你的数据传输比别人快几毫秒 → 提前反应
- 比如：期货先动，股票指数慢半拍，你可以提前抢跑
- 壁垒：FPGA、微波链路、co-location

### 订单流预测

- 分析订单簿数据，预测短期订单流向
- 提前挂单，等别人来成交
- 壁垒：低延迟、数据分析能力

### 闪电跨所套利

- 同一资产在两个交易所价差出现的瞬间，同时买入卖出
- 速度要求：微秒级
- 基本是 Jump、Citadel 这类机构的游戏

### 技术栈

- FPGA 硬件加速
- 内核旁路（DPDK / Solarflare）
- co-location（服务器放在交易所机房）
- 微波/激光链路（比光纤快）

## 另类数据驱动类

### 核心逻辑

**用别人还没用到的数据，获得信息优势。**

### 常见另类数据

| 数据类型 | 例子 | 应用场景 |
|---------|------|---------|
| **舆情数据** | 新闻情绪、社交媒体情绪、分析师评级变化 | 短线交易、事件驱动 |
| **卫星数据** | 停车场车流量、油田储量、集装箱吞吐量、零售屋顶太阳能板 | 预测公司营收、行业供需 |
| **信用卡/消费数据** | 零售商刷卡消费趋势 | 提前知道财报好坏 |
| **网络流量数据** | 电商网站访问量、App 下载量 | 互联网公司营收预测 |
| **供应链数据** | 航运数据、铁路货运量 | 宏观经济预测 |
| **手机位置数据** | 商场人流量 | 零售公司销售预测 |

### 代表机构

Two Sigma、文艺复兴、Point72。
另类数据是新 Alpha 的重要来源，但成本很高——数据采购、清洗、分析都需要大量投入。

### 失效条件
- 当大家都开始用同样的数据，信息优势就消失了
- 数据质量参差，很多另类数据其实没有预测力

## ML / AI 驱动类

### 核心逻辑

**ML 不是预测神器，是从大量弱信号中提取模式的工具。**

### 具体应用方向

| 方向 | 做什么 | 成熟度 |
|------|--------|--------|
| **GBDT/Transformer 因子挖掘** | 从几百个特征中自动找 Alpha 信号 | 高（行业主流） |
| **深度强化学习做市** | RL 动态优化做市报价策略 | 中（头部机构在用） |
| **RL 执行优化** | 最优拆单算法 | 中-高 |
| **NLP 新闻交易** | 实时解读新闻，自动生成交易信号 | 中 |
| **元标签（Meta-Labeling）** | ML 不预测方向，预测基础信号的成功率，优化仓位 | 高（推荐做法） |
| **深度学习时序预测** | Transformer/LSTM 预测价格 | 低（容易过拟合，不如 GBDT） |

### 核心原则（重申）
- 先用简单规则模型做 baseline，ML 是优化工具，不是起点
- 过拟合防御比模型复杂度重要 100 倍
- ML 擅长弱信号叠加，不擅长预测强趋势或拐点

## 加密货币特有策略

### 核心逻辑

**加密市场效率更低、结构更原始，存在很多传统市场已经消失的套利机会。**

### 跨所套利

- 同一币种在不同交易所价格不一致
- 现在空间已经很小（机器人太多），大所之间价差基本被抹平
- 小所、新上币还有机会

### 三角套利

- 三个币对之间交叉定价不一致
- 速度极快，基本是高频机器人的游戏

### 流动性提供（LP）

- 在 Uniswap 等 DEX 上提供流动性，赚手续费
- **风险**：无常损失（Impermanent Loss）

### 资金费率套利

- 永续合约资金费率 和 现货价格 的基差套利
- 多头资金费率为正时，买现货 + 空永续，赚资金费

### MEV（最大可提取价值）

- 三明治攻击：抢在大额交易前后下单，夹挤
- 清算机器人：自动清算爆仓仓位
- 本质是区块链交易顺序的套利

## 策略选型决策树

```
你的资金规模是？
  ├─ < 100 万人民币
  │    └─ 你有什么技术能力？
  │         ├─ 会 Python、能做回测 → CTA 趋势跟踪、因子投资、事件驱动
  │         ├─ 会统计建模 → 统计套利、配对交易、均值回归
  │         └─ 只有交易经验 → 价格行为、供需区、趋势跟踪（手动交易）
  │
  ├─ 100 万 ~ 1000 万
  │    └─ 你的优势是什么？
  │         ├─ 数据能力强 → 另类数据策略、多因子统计套利
  │         ├─ 技术能力强 → 做市、期现套利、资金费率套利
  │         └─ 研究能力强 → 事件驱动、宏观量化、因子投资
  │
  └─ > 1000 万
       └─ 你能组建团队吗？
            ├─ 能 → 多策略组合（趋势 + 套利 + 做市 + 因子）
            └─ 不能 → 选 1-2 个你有优势的方向做精
```

### 关键提醒

1. **不要什么策略都做**——找到你有优势的那一类，做到极致。
2. **策略会衰减**——永远在开发新策略，不要等旧的失效了才找新的。
3. **分散化是必须的**——不同类型的策略组合起来，收益更稳、回撤更小。
4. **过拟合是最大的敌人**——回测好看不算数，样本外真金白银验证才算数。
5. **风控比收益重要**——活下来比赚得多重要，一次爆仓就结束了。
