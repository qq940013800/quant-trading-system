# 非滞后指标体系

> 严格来说所有指标都是滞后的（都基于历史数据），但"非滞后"通常指**不是移动平均平滑出来的、对价格变化反应更快的指标**。

## 第一性原理

### 什么是滞后？

**滞后 = 指标变化比价格变化慢。**

- 移动平均是最典型的滞后指标：10 日均线 = 过去 10 天收盘价的平均，价格已经涨了好几天，均线才开始往上走。
- 滞后指标的问题：入场晚、出场晚，利润回吐大。

### 为什么需要非滞后指标？

**目标：更快捕捉价格变化，减少利润回吐。**

但要注意：
- 越快的指标 → 噪音越多 → 假信号越多
- 没有完美指标，只有 trade-off

### 指标分类逻辑

```
滞后程度
  ↑
  │  移动平均(MA)、MACD、均线包络线
  │  ─────────────────────────
  │  RSI、KDJ、CCI、ATR（中等）
  │  ─────────────────────────
  │  价格行为、成交量、支撑阻力、订单流（最领先）
  ↓
```

## 价格行为类

### 最领先的指标就是价格本身

所有指标都是价格的衍生物，**价格本身是最快的指标**。

| 指标 | 说明 | 领先程度 |
|------|------|---------|
| **K线形态** | 吞没、锤子线、十字星、Pin Bar | ⭐⭐⭐⭐⭐ |
| **高低点结构** | swing high / swing low、高点更高/低点更低 | ⭐⭐⭐⭐⭐ |
| **价格突破** | 突破前高/前低、区间边界 | ⭐⭐⭐⭐⭐ |
| **缺口** | 跳空高开/低开 | ⭐⭐⭐⭐⭐ |
| **收盘价位置** | 收在最高/最低/中间 | ⭐⭐⭐⭐ |

### 关键洞察

- **价格行为不需要计算**，直接看 K 线就知道
- 但缺点是主观性强，不同人解读不一样
- 所以需要量化规则来定义什么是"突破"、什么是"吞没"

## 成交量与持仓量类

### 成交量（Volume）

**原理：价格变化需要成交量确认。**

- 放量上涨 = 真突破
- 缩量上涨 = 假突破（可能是诱多）
- 放量下跌 = 真跌
- 缩量下跌 = 跌不动了

| 指标 | 说明 |
|------|------|
| **成交量** | 当日总成交量 |
| **OBV**（能量潮） | 累计成交量，涨加跌减 |
| **VWAP**（成交量加权平均价） | 机构常用的均价参考 |
| **成交量分布** | 在哪个价格区间成交量最大（价值区域） |

### 持仓量（Open Interest）

**期货特有指标：未平仓合约数量。**

- 价格涨 + 持仓量增 = 新资金入场，趋势可能继续
- 价格涨 + 持仓量减 = 旧资金平仓，趋势可能结束
- 价格跌 + 持仓量增 = 新空入场，下跌趋势继续
- 价格跌 + 持仓量减 = 空单平仓，下跌可能结束

## 振荡器类

### RSI（相对强弱指数）

**原理：衡量一段时间内上涨幅度占总幅度的比例。**

- RSI > 70 = 超买（可能回调）
- RSI < 30 = 超卖（可能反弹）
- RSI = 50 = 多空平衡

**优点：比 MA 反应快。**
**缺点：强趋势中可以一直超买/超卖，不回调。**

### 随机指标（KDJ / Stochastic）

**原理：当前收盘价在最近 N 天价格区间中的位置。**

- K > 80 = 超买
- K < 20 = 超卖
- K 线上穿 D 线 = 金叉（买入信号）

**比 RSI 更敏感，但噪音也更多。**

### CCI（商品通道指数）

**原理：价格与统计平均的偏离程度。**

- CCI > +100 = 超买
- CCI < -100 = 超卖
- 擅长捕捉趋势启动初期

### Williams %R

**原理：和随机指标类似，但方向相反。**

- 衡量收盘价在区间中的位置
- 比 KDJ 更简单直接

## 波动率类

### ATR（平均真实波幅）

**原理：衡量价格波动的幅度，不是方向。**

- ATR 大 = 波动大，趋势可能强
- ATR 小 = 波动小，可能盘整
- 常用于设置止损（止损 = 入场价 ± 2×ATR）

**注意：ATR 本身是平滑的，有一定滞后，但比 MA 快。**

### 布林带宽度

**原理：布林带上下轨之间的距离。**

- 带宽收窄 = 波动率压缩，可能即将突破
- 带宽扩大 = 波动率放大，趋势已经启动
- "挤压"（squeeze）策略就是基于这个

### 历史波动率（HV）

**原理：过去 N 天收益率的标准差。**

- 用于判断当前市场是平静还是疯狂
- 波动率均值回归是常见规律

## 支撑阻力与结构类

### 枢轴点（Pivot Points）

**原理：根据前一天的高低收计算当天的支撑阻力位。**

```
Pivot = (High + Low + Close) / 3
R1 = 2×Pivot - Low
S1 = 2×Pivot - High
R2 = Pivot + (High - Low)
S2 = Pivot - (High - Low)
```

**日内交易常用，开盘就能算出今天的关键位。**

### 供需区 / 订单块

**原理：机构大单成交的位置，会成为支撑或阻力。**

- 供需区不是滞后指标，是价格位置本身
- 价格回到供需区，可能反弹或回落

### 流动性水平（Liquidity Pools）

**ICT / SMART MONEY 概念：**
- 前高、前低、整数关口 = 流动性聚集的地方
- 价格往往先扫掉这些位置的止损，再反转
- "流动性猎杀"就是基于这个逻辑

## 订单流类

### 最领先的指标：订单流

**原理：直接看市场上的买卖挂单和成交情况。**

| 指标 | 说明 |
|------|------|
| **DOM**（深度市场） | 买卖盘口挂单量 |
| **成交量分布** | 逐笔成交的主动买/主动卖比例 |
| **足迹图**（Footprint） | 每个价格上的买卖成交细节 |
| **Delta** | 主动买量 - 主动卖量 |

**优点：最接近真实的市场情绪。**
**缺点：需要 Level 2 数据，散户很难拿到。**

## 指标对比速查表

| 指标 | 类型 | 滞后程度 | 优点 | 缺点 |
|------|------|---------|------|------|
| **K线形态** | 价格行为 | 无滞后 | 最直接、最快 | 主观、噪音多 |
| **支撑阻力位** | 结构 | 无滞后 | 关键位明确 | 主观性强 |
| **成交量** | 量能 | 轻微滞后 | 确认价格真伪 | 不预测方向 |
| **OBV** | 量能 | 轻微滞后 | 量价结合 | 噪音较多 |
| **VWAP** | 量价 | 中等 | 机构标准 | 日内参考为主 |
| **RSI** | 振荡器 | 中等 | 超买超卖清晰 | 强趋势中失效 |
| **KDJ** | 振荡器 | 中等偏快 | 金叉死叉明确 | 噪音多、假信号多 |
| **CCI** | 振荡器 | 中等偏快 | 捕捉趋势启动 | 不稳定 |
| **ATR** | 波动率 | 中等 | 止损设置好用 | 不指示方向 |
| **布林带宽度** | 波动率 | 中等 | 预警突破 | 需要配合方向判断 |
| **MA（移动平均）** | 趋势 | 严重滞后 | 趋势清晰 | 入场晚、回吐大 |
| **MACD** | 趋势 | 严重滞后 | 经典、成熟 | 本质是 MA 的 MA |

## 实战使用原则

### 1. 不要追求"完美领先指标"

所有指标都有 trade-off：
- 越领先 → 噪音越多 → 假信号越多
- 越滞后 → 信号越可靠 → 但入场晚

**正确做法：快慢结合，用慢指标定方向，用快指标找入场点。**

### 2. 价格是第一位的

**所有指标都是价格的衍生物。** 不要舍本逐末：
- 先看价格结构（趋势还是震荡）
- 再看成交量确认
- 最后用振荡器找精确入场点

### 3. 指标组合比单一指标重要

**经典组合：**
- 趋势：MA（定方向）+ RSI（找入场点）
- 突破：布林带收窄（预警）+ 价格突破（确认）
- 反转：RSI 超买超卖 + K线形态（双重确认）

### 4. 警惕"过度优化"

不要为了某个指标调参数调到完美——那是过拟合。
参数越少、越简单，策略越健壮。
