## 第一性原理

### 为什么仓位管理是第一优先级？

**复利的敌人是中断。**

| 回撤幅度 | 回本需要的涨幅 |
|---------|--------------|
| 10% | 11.1% |
| 20% | 25% |
| 30% | 42.9% |
| 50% | 100% |
| 70% | 233% |
| 90% | 900% |

**结论**：亏损是非线性的。亏 50% 需要赚 100% 才能回本。所以控制回撤 = 保护复利曲线。

### 仓位管理的本质

仓位管理不是"选多少股票"，而是回答三个问题：

1. **单笔交易冒多大风险？** → 决定你在单笔亏损时死不死
2. **整个组合冒多大风险？** → 决定你在连续亏损时死不死
3. **不同策略之间怎么分配风险？** → 决定你的分散化是否有效

### 第一性推导

- 假设你有一个正期望的策略（期望值 > 0）
- 仓位太轻 → 虽然不会死，但赚得太少
- 仓位太重 → 虽然赚得多，但一次黑天鹅就归零
- **最优仓位 = 在"不爆仓"和"收益最大化"之间找平衡**

这就是 Kelly 公式想解决的问题。

## 基础方法：固定比例法

### 等比例仓位

```
每个仓位 = 总资金 × 固定比例
```

**例子**：100 万资金，每个仓位 10% → 同时持有 10 个标的。

**优点**：简单、客观、容易执行。
**缺点**：没有考虑不同标的的风险差异——波动大的和波动小的配一样多，不合理。

### 固定金额法

```
每个仓位 = 固定金额（比如 10 万）
```

**优点**：更简单。
**缺点**：资金增长后不会自动调整，要么太保守要么太激进。

### 适用场景

- 初学者、手动交易、信号不复杂的策略
- 不适合机构级组合管理

## Kelly 公式：理论最优解

### 公式

```
f* = (p × b - q) / b
```

- f*：最优仓位比例（占总资金的比例）
- p：胜率
- q：败率 = 1 - p
- b：盈亏比（平均盈利 / 平均亏损）

### 直觉理解

- 胜率越高 → 仓位越重
- 盈亏比越高 → 仓位越重
- 胜率和盈亏比的乘积决定期望值

### 例子

- 胜率 p = 40%，败率 q = 60%
- 盈亏比 b = 2（平均赚 2R，平均亏 1R）
- f* = (0.4 × 2 - 0.6) / 2 = (0.8 - 0.6) / 2 = 0.1 = 10%

→ 每次投入总资金的 10%。

### 为什么实战不用全 Kelly？

#### 问题 1：估计误差
- 你估计的胜率和盈亏比是错的（有样本误差）
- 如果真实胜率比你估计的低，全 Kelly 会让你亏更多
- 估计偏 10%，全 Kelly 的结果可能差 50%

#### 问题 2：回撤太大
- 全 Kelly 的最大回撤可能达到 50%~80%
- 心理上根本扛不住，会在底部割肉

#### 问题 3：不适合多策略组合
- 每个策略都用全 Kelly，加起来仓位可能超过 100%
- 策略之间有相关性，实际风险比你想象的大

### 实战修正：分数 Kelly

```
实际仓位 = f* / k
```

- k = 2 ~ 4（常用 1/2 Kelly 或 1/4 Kelly）
- 牺牲一部分收益，换大幅降低波动和回撤
- **长期来看，分数 Kelly 的实际收益可能比全 Kelly 还高**——因为你不会中途爆仓

### 经验法则

| 策略类型 | 推荐 Kelly 倍数 |
|---------|---------------|
| 高置信度、样本充足 | 1/2 Kelly |
| 中等置信度 | 1/4 Kelly |
| 新策略、样本少 | 1/8 Kelly |
| 高度不确定 | 0（先小仓位测试） |

## 波动率目标法：机构主流

### 核心思想

**不按资金分配，按风险分配。波动大的少配，波动小的多配，让每个标的贡献的风险相等。**

### 公式

```
仓位 = 目标波动率 / 实际波动率
```

**例子**：
- 组合目标年化波动率 = 10%
- 标的 A 的年化波动率 = 20%
- → 仓位 = 10% / 20% = 50%

### 为什么有效？

1. **自动调仓**：波动大的时候自动减仓，波动小的时候自动加仓
2. **风险恒定**：不管市场怎么变，组合的风险敞口保持稳定
3. **适合多资产**：股票、债券、商品波动率差异很大，按资金配不合理

### 进阶：风险贡献相等

```
每个资产对组合总风险的贡献相等
```

这就是**风险平价（Risk Parity）**的核心思想。

### 代表机构

Bridgewater（全天候基金）、AQR、Man Group。
波动率目标法是机构级组合管理的主流方法。

## 风险平价：多资产配置

### 核心原理

传统的 60/40 股债组合，看起来是"分散"，实际上：
- 股票波动大，贡献了组合 90% 以上的风险
- 债券波动小，贡献不到 10% 的风险
- → 本质上还是"股票组合"

风险平价的做法：
- 股票波动大 → 少配资金
- 债券波动小 → 多配资金
- 加杠杆把债券部分的收益提上来
- → 每个资产贡献的风险相等

### 公式（简化版）

```
w_i ∝ 1 / σ_i
```

- w_i：资产 i 的权重
- σ_i：资产 i 的波动率
- 波动率越高，权重越低

### 优缺点

✅ 优点：
- 真正的分散化（风险维度的分散）
- 不依赖收益率预测（收益率预测最不准）
- 跨周期表现更稳定

❌ 缺点：
- 需要加杠杆（加杠杆就有爆仓风险）
- 利率上升周期，债券部分会亏很多
- 不是"无脑最优"，有其适用边界

## 固定 R 倍数法：实战推荐

### 这是个人交易者最实用的方法

**核心规则**：每笔交易的最大亏损 = 总资金 × 固定比例。

### 计算步骤

```
第一步：定单笔风险比例（通常 1% ~ 2%）
第二步：定止损距离（入场价 - 止损价）
第三步：算仓位

仓位 = (总资金 × 风险比例) / 止损距离
```

### 例子

- 总资金：100 万
- 单笔风险：1% = 1 万
- 止损距离：2%（入场价 100，止损价 98）
- → 仓位 = 1 万 / 2% = 50 万

### 为什么推荐这个方法？

1. **简单**：一个公式算清楚
2. **风控明确**：亏多少你一开始就知道
3. **自适应**：止损宽的仓位小，止损窄的仓位大——自动调整
4. **符合第一性原理**：你是在控制"最大可能亏损"，而不是"买多少股"

### 不同风险偏好的参数

| 风格 | 单笔风险比例 | 最大回撤预期 |
|------|------------|------------|
| 保守型 | 0.5% | < 10% |
| 平衡型 | 1% | 10% ~ 15% |
| 激进型 | 2% | 15% ~ 25% |
| 赌徒型 | > 5% | 可能爆仓 |

## 马丁格尔与反马丁格尔

### 马丁格尔（Martingale）

**规则**：亏了就加倍下注，赢回来就回本。

**例子**：
- 第一次下 1 万，亏了
- 第二次下 2 万，又亏了
- 第三次下 4 万，再亏了
- ...

**为什么这是自杀？**
- 连亏 10 次，你需要的资金是初始仓位的 1024 倍
- 只要遇到一次长连亏，就彻底爆仓
- **长期来看，马丁格尔 = 必然爆仓**

### 反马丁格尔（Anti-Martingale）

**规则**：赢了就加仓，亏了就减仓。

- 赚钱的仓位 → 加码（让利润奔跑）
- 亏钱的仓位 → 减码（截断亏损）
- 这才是正确的方向

### 海龟交易法的加仓逻辑

海龟是典型的反马丁格尔：
- 入场后每涨 0.5×ATR 加一次仓
- 最多加 4 次
- 浮盈越大，仓位越重
- → 趋势来了赚大钱，趋势错了亏小钱

## 多策略组合的仓位分配

### 问题

你有 5 个策略，每个都觉得不错，资金怎么分？

### 方法 1：等风险分配

```
每个策略分配相等的风险预算
```

- 不按资金分，按风险分
- 波动大的策略少配资金，波动小的多配资金
- 每个策略对组合的风险贡献相等

### 方法 2：按历史 Sharpe 分配

```
权重 ∝ Sharpe²
```

- 历史 Sharpe 越高，配的资金越多
- 但要注意：历史 Sharpe 不代表未来 Sharpe

### 方法 3：核心-卫星结构

- **核心仓位**（70%~80%）：低波动、稳定的策略（比如因子投资、宏观趋势）
- **卫星仓位**（20%~30%）：高波动、高收益的策略（比如短线交易、事件驱动）

### Millennium 的 Pod 模式

顶级对冲基金 Millennium 有 200+ 个交易小组（pod）：
- 每个 pod 有独立的风险预算（比如年化波动目标 10%）
- 亏到一定程度就降仓/清盘
- 平台负责风控、运营、技术
- 单个 pod 亏再多，也不影响整体

**核心思想**：分散化到极致——不是分散持仓，是分散策略和策略经理。

## 回撤调整仓位：动态降险

### 静态仓位的问题

如果你用固定仓位策略，遇到连续回撤，会发生什么？
- 资金从 100 万跌到 80 万（回撤 20%）
- 但你还在按 100 万的标准下注
- → 风险敞口其实变大了（因为本金少了）

### 动态调整规则

**规则 1：回撤降仓法**
```
当前回撤 < 5% → 正常仓位
回撤 5%~10% → 仓位降 50%
回撤 > 10% → 暂停交易，重新评估
```

**规则 2：波动率目标法**
- 组合实际波动率超过目标 → 自动减仓
- 组合实际波动率低于目标 → 自动加仓

**规则 3：日亏限额**
- 单日亏损达到总资金的 X% → 当天停止交易
- 理由：人在连续亏损时容易上头，做傻事

### 三级回撤控制体系

| 级别 | 触发条件 | 动作 |
|------|---------|------|
| 预警线 | 回撤 5% | 检查策略，不加仓也不减仓 |
| 降仓线 | 回撤 10% | 整体仓位降 50% |
| 清盘线 | 回撤 15%~20% | 全部平仓，暂停，重新研究 |

## 蒙特卡洛验证：压力测试

### 为什么需要蒙特卡洛？

回测告诉你的是"历史上这个策略表现如何"，但你不知道：
- 历史上的路径是不是最好的情况？
- 如果交易顺序换一下，结果会怎样？
- 最坏情况下最大回撤有多大？

### 蒙特卡洛模拟怎么做？

1. 从你的历史交易记录中，随机抽取 N 笔交易（有放回）
2. 计算这 N 笔交易的累计收益和最大回撤
3. 重复 1000 次、10000 次
4. 看分布：最坏的 5% 情况是什么样？

### 你会发现什么？

- 回测里最大回撤 15%，蒙特卡洛可能告诉你最坏情况是 40%
- 这才是你真正应该担心的回撤

### 仓位管理的验证

用蒙特卡洛回答：
- 单笔风险 1%，爆仓概率是多少？
- 单笔风险 2%，最大回撤分布是什么样？
- 连续亏 10 次的概率有多大？

**结论再调参，不要拍脑袋定仓位。**

## 常见误区与禁忌

### ❌ 误区 1：满仓单一标的

- 哪怕你再看好，也不要满仓一只股票
- 黑天鹅来了，没有任何机会逃跑

### ❌ 误区 2：亏损加仓（摊平成本）

- 跌了就买更多，"摊低成本"
- 这是马丁格尔的变种
- 趋势真的反转了，你会亏得更多
- **正确做法**：亏损的仓位应该减，不是加

### ❌ 误区 3：盈利减仓

- 赚了一点就跑，"落袋为安"
- 这是截断利润，让亏损奔跑——完全反了
- **正确做法**：赚钱的仓位可以加（反马丁格尔），亏钱的仓位要减

### ❌ 误区 4：不设止损

- "我再等等，它会回来的"
- 很多股票再也回不来了
- **止损是必须的，不是可选的**

### ❌ 误区 5：杠杆乱用

- 杠杆不创造收益，只放大已有收益和已有错误
- 策略本身不赚钱，加杠杆只会亏得更快
- LTCM：两个诺贝尔奖得主，杠杆 25 倍，一次俄罗斯债务违约就没了

### ❌ 误区 6：资金管理和策略脱节

- 仓位管理不是独立的，要和策略的胜率、盈亏比匹配
- 高胜率低盈亏比的策略，和低胜率高盈亏比的策略，仓位方法应该不同

## 计算速查表

### 单笔仓位计算（固定 R 倍数法）

```
仓位 = (总资金 × 单笔风险%) / (入场价 - 止损价)
```

### Kelly 最优仓位

```
f* = (p × b - q) / b
实际仓位 = f* / 分数 (1/2 或 1/4)
```

### 波动率目标法

```
仓位 = 目标波动率 / 标的实际波动率
```

### 风险平价权重

```
w_i ∝ 1 / σ_i
（波动率越高，权重越低）
```

### 回撤降仓规则

```
回撤 < 5%  → 100% 仓位
5%~10%     → 50% 仓位
> 10%      → 0% 仓位（暂停）
```

### 常用参数参考

| 参数 | 保守 | 平衡 | 激进 |
|------|------|------|------|
| 单笔风险 | 0.5% | 1% | 2% |
| Kelly 倍数 | 1/4 | 1/3 | 1/2 |
| 目标波动率 | 8% | 12% | 18% |
| 最大回撤容忍 | 10% | 15% | 25% |
| 同时持仓数 | 5~8 | 8~12 | 12~20 |
