## 第一性原理

### 核心
不要从"别人怎么做"出发，要从最基本的事实和真理出发，一步步推导。

### 在交易中的应用

**问题：这个策略为什么有效？**

❌ 错误问法："别人用这个策略赚钱了吗？"
✅ 正确问法：
1. 价格是什么？（信息 + 流动性 + 噪声）
2. 我的策略赚的是哪部分的钱？
3. 这部分钱为什么存在？
4. 为什么别人不赚这个钱？
5. 这个钱什么时候会消失？

**例子：**
- 动量策略为什么有效？
  - 不是因为"大家都说动量有效"
  - 第一性推导：人有处置效应（卖早了）+ 羊群效应 + 信息逐步扩散 → 价格趋势会自我延续
  - 这个逻辑什么时候会失效？→ 当大多数人都知道动量效应，开始抢先交易的时候

## 逆向思维

### 核心
反过来想，总是反过来想。想知道怎么成功，先研究怎么失败。

### 在交易中的应用

**问题：怎么做这个策略一定会亏钱？**

把所有导致失败的原因列出来，然后逐一避免。

**例子：**
- 趋势跟踪策略怎么会死？
  1. 震荡市——来回打脸，连续止损
  2. 仓位太重——一次假突破就爆仓
  3. 止损太宽——小亏变大亏
  4. 不止损——死扛，一次回到解放前
  5. 太频繁交易——手续费吃掉所有利润
  6. 策略太拥挤——大家都在做，收益衰减

→ 然后针对每一条设计防御措施。

**查理·芒格说："如果我知道我会死在哪里，我就永远不去那个地方。"**

## 概率思维

### 核心
世界不是非黑即白的，所有事情都是概率。不要问"会不会发生"，要问"概率有多大"。

### 在交易中的应用

**不要说"这只股票会涨"，要说"这只股票有 60% 的概率涨 10%，40% 的概率跌 5%"。**

### 期望值思维

```
期望值 = 胜率 × 平均盈利 - 败率 × 平均亏损
```

只要期望值为正，重复做，长期一定赚钱。

**例子：**
- 胜率 40%，平均赚 2R，平均亏 1R
- 期望值 = 0.4 × 2 - 0.6 × 1 = 0.2R
- 每笔交易平均赚 0.2R——虽然大部分时候是亏的，但长期是赚的

### 概率思维的训练

- 不要为单次结果后悔——只要决策过程对了，结果不好也是好决策
- 不要被单次结果迷惑——单次赚钱的决策可能是错的，单次亏钱的决策可能是对的
- 关注过程，不要只看结果

## 能力圈

### 核心
知道自己知道什么，不知道什么。在能力圈内做事，外面的不碰。

### 在交易中的应用

**问题：这个策略真的在我的能力圈内吗？**

- 你真的理解这个市场的微观结构吗？
- 你真的理解这个策略的逻辑吗？
- 出了问题，你能诊断原因吗？
- 你能比市场上其他人更懂这个领域吗？

### 能力圈的边界

- 能力圈不需要很大，关键是**知道边界在哪**。
- 巴菲特："我不碰科技股，不是因为科技股不好，是因为我不懂。"
- 量化交易也一样：不要看到什么策略热就去做，先问自己"我真的理解这个吗？"

### 扩展能力圈

- 能力圈可以慢慢扩大，但不要一下子跳出去。
- 从你已经懂的领域，慢慢往外延伸。
- 不懂的时候，要么学懂，要么不碰。

## 安全边际

### 核心
不要把仓位卡得太满，留出错判的空间。

### 在交易中的应用

**安全边际 = 你的判断 和 实际情况之间的缓冲带。**

- 你觉得值 10 块，8 块买才有安全边际
- 你觉得止损在 9.5 块，设在 9.3 块才有安全边际（防止被扫损）
- 你觉得最大回撤 10%，按 15% 做预案才有安全边际

### 为什么需要安全边际

因为：
1. 你的判断可能是错的
2. 市场可能比你想的更极端
3. 黑天鹅总会来

**安全边际不是浪费，是保险。**

## 二阶思维

### 核心
做决策的时候，不要只看直接结果，还要看结果的结果，以及结果的结果的结果……

### 在交易中的应用

**一阶思维**："这个策略回测 Sharpe 2.0，好棒！"
**二阶思维**："这个策略为什么 Sharpe 这么高？是不是过拟合了？"
**三阶思维**："如果这个策略真的有效，为什么别人不做？是不是有什么我没看到的坑？"

### 拥挤交易的二阶效应

- 一阶：这个因子有效，我要加仓
- 二阶：大家都来加这个因子，收益会被摊薄
- 三阶：当大家都开始撤的时候，会发生踩踏
- 四阶：踩踏的时候，流动性消失，想跑都跑不掉

## 系统思维

### 核心
不要只看单个事件，要看整个系统。系统里的各个部分是相互关联、相互影响的。

### 在交易中的应用

**交易系统是一个整体：**
- 数据质量 → 影响信号准确性
- 信号质量 → 影响胜率
- 仓位管理 → 影响回撤
- 执行质量 → 影响滑点
- 风控 → 影响生存

**任何一个环节出问题，整个系统都会受影响。**

### 反馈回路

- 正反馈：赚钱 → 加仓 → 赚更多 → 再加仓 → 一旦反转，亏更多
- 负反馈：亏钱 → 减仓 → 风险降低 → 慢慢恢复

**好的系统要有负反馈机制——比如回撤自动减仓。**

## 系统思维深化（系统动力学视角）

### 核心工具：存量与流量

**存量**：系统中积累的东西（比如你的总资金、持仓量、策略拥挤度）
**流量**：流入和流出存量的速度（比如每日盈亏、新开仓/平仓数）

**关键洞察：存量变化滞后于流量变化。**

- 流量是"每天赚 1% "，存量是"总资金"
- 你感觉"策略最近表现好"的时候，可能已经是峰值了
- 你感觉"策略不行了"的时候，可能已经见底了

### 系统杠杆点

系统思考大师 Donella Meadows 说：每个系统都有杠杆点——在那里做一个小改变，能带来大结果。

| 杠杆点（从弱到强） | 交易系统对应 |
|------------------|------------|
| 调整参数 | 调止损宽度、调仓位比例 |
| 调整规则 | 加一个过滤器、改出场条件 |
| 调整反馈回路 | 加回撤自动减仓、加策略监控 |
| 调整系统目标 | 从"追求高收益"改成"控制最大回撤" |

**大多数人在最底层（调参数）努力，真正的改变发生在更高层（改目标、改反馈）。**

### 常见系统陷阱

1. **转移负担**：问题出现了，不去找根因，只治标
   - 交易中的表现：策略回撤了，不去优化逻辑，只去调参数
   - 正确做法：问"为什么回撤？是市场变了？还是逻辑失效了？"

2. **公地悲剧**：所有人都用同一个策略，最后所有人都不赚钱
   - 交易中的表现：动量因子拥挤、CTA 拥挤
   - 应对：找 niche、找小市场、不断开发新策略

3. **时间延迟**：系统的反馈不是即时的
   - 交易中的表现：你改了策略，要等几个月才知道效果好不好
   - 应对：小步快跑、快速验证、不要一次改太多东西

4. **舍本逐末**：只看指标，不看系统结构
   - 交易中的表现：盯着每天的盈亏，不看长期的期望值
   - 应对：关注过程指标（执行质量、风险控制），不要只看结果

## 编程思维（量化开发专用）

### 模块化思维

**把大问题拆成小模块，每个模块只做一件事，然后组装起来。**

交易系统的模块划分：
```
数据模块 → 特征模块 → 信号模块 → 风控模块 → 执行模块 → 监控模块
```

**好处：**
- 出了问题好定位——是数据错了？还是信号错了？
- 可以单独测试每个模块
- 换一个模块不影响其他部分

**反模式：**
- 一个 1000 行的脚本，从数据下载到下单全在里面
- 改一个小地方，要担心会不会搞坏其他地方

### 抽象与分层

**上层不知道下层的实现细节，下层不关心上层怎么用它。**

```
研究层（策略逻辑）
    ↑
回测层（模拟交易）
    ↑
数据层（K线数据）
```

**交易系统的分层：**
- **第一层：数据**——你只需要知道"给我时间戳和OHLCV"，不需要知道它是从 MT5 拉的还是从 CSV 读的
- **第二层：特征**——你只需要知道"给我ADX和ATR"，不需要知道它怎么算的
- **第三层：信号**——你只需要知道"给我一个方向"，不需要知道它用了什么指标
- **第四层：风控**——你只需要知道"这个仓位合不合法"，不需要知道它怎么算的
- **第五层：执行**——你只需要知道"给我下单"，不需要知道它用了什么算法

**为什么要分层？**
- 换数据库不用改策略代码
- 换经纪商不用改信号代码
- 测试某一层可以 mock 其他层

### 因果性思维（编程层面）

**代码里的每一行计算，都要问：这行代码用的数据，在那个时间点真的能拿到吗？**

```python
# ❌ 错误：用了未来数据
ma20 = close.rolling(20).mean()
signal = close > ma20
# 这里的 ma20 是用了包括当前 bar 在内的 20 根算的
# 但实盘中，你在当前 bar 收盘前是不知道收盘价的

# ✅ 正确：shift(1) 确保只用过去的数据
ma20 = close.rolling(20).mean().shift(1)
signal = close > ma20
# 这里的 ma20 是用截止到上一根 bar 的数据算的——实盘能拿到
```

**这是量化交易编程的第一死罪——前视偏差。**

### 测试思维

**每写一行代码，就想怎么测试它。**

1. **单元测试**：每个函数单独测
   - 给一个输入，输出是不是预期的？
   - 边界情况对不对？（空数据、极端值、NaN）

2. **因果性测试**：这个函数有没有前视偏差？
   - 改未来的数据，输出会不会变？
   - 如果会变，就是有前视

3. **回归测试**：改了代码，原来的功能有没有坏？
   - 每次改完，跑一遍所有测试
   - 不要"我觉得应该没问题"

### 实验管理思维

**每一次实验都要可复现、可追溯。**

- 随机种子要固定——同样的输入，同样的输出
- 参数要记录——这次实验用了什么参数？
- 结果要保存——这次实验的回测结果是什么？
- 决策规则要提前定好——不要看着结果调参数

**反模式：**
- 跑了 100 次实验，只留最好的那一次
- 不知道这次实验和上次有什么区别
- 改了参数，忘了改回来

### 增量开发思维

**不要一口气写 1000 行代码然后调试。要小步快跑。**

正确流程：
1. 先写一个最简单的版本（比如均线交叉）
2. 跑通，测试通过
3. 再加一个功能（比如加 ATR 止损）
4. 跑通，测试通过
5. 再加一个功能（比如加仓位管理）
6. 跑通，测试通过

**好处：**
- 出了问题，你知道是新功能搞坏的
- 随时有一个能跑的版本
- 不会最后才发现"原来一开始就错了"

### 可复现性思维

**三个月后你回来，还能复现今天的结果吗？**

- 代码在 Git 里有版本
- 数据有快照
- 参数有配置文件
- 随机种子固定
- 环境有 requirements.txt / pyproject.toml

**顶级机构和个人交易员的最大区别之一：可复现性。**

## 机会成本

### 核心
你选了 A，就放弃了 B。放弃的那个，就是你的机会成本。

### 在交易中的应用

**问题：我把资金放在这个策略上，是不是最好的选择？**

- 我有 10 个策略，每个都想要资金，应该怎么分配？
- 这个策略年化 15%，另一个 20%，为什么我还要做这个？
- 我花了 3 个月开发这个策略，值不值？（沉没成本不是成本，未来的收益才是）

### 沉没成本谬误

- "我已经花了这么多时间在这个策略上，放弃太可惜了"
- → 不对！过去的投入已经收不回来了，要看未来这个策略能不能赚钱
- 不行的策略，及时止损，把资源放到更好的地方

## 均值回归

### 核心
极端的情况会回归平均水平。涨多了会跌，跌多了会涨。

### 在交易中的应用

- **短期超额收益会回归**：一个策略连续赚了 6 个月，接下来可能要歇一歇
- **波动率会回归**：波动特别大的时候，后面通常会平静下来
- **相关性会回归**：大家都一起涨/一起跌的时候，后面会分化

### 注意

均值回归是有前提的：
- 长期趋势还是存在的（比如牛市里的回调，不是反转）
- 不要和趋势对着干——"接飞刀"是最危险的

## 复利与杠杆

### 核心
小的稳定增长，长期下来是惊人的。杠杆放大收益，也放大亏损。

### 在交易中的应用

**复利的力量：**
- 年化 15%，10 年涨 4 倍，20 年涨 16 倍
- 关键是**不要中断**——一次大亏就能把十年的复利毁掉

**杠杆的真相：**
- 杠杆不创造收益，只放大已有收益和已有错误
- 策略本身不赚钱，加杠杆只会亏得更快
- 再好的策略，杠杆太高也会爆仓

**教训：LTCM——两个诺贝尔奖得主，杠杆 25 倍，一次俄罗斯债务违约就没了。**

## 确认偏误

### 核心
人天生倾向于寻找支持自己观点的证据，忽略反对的证据。

### 在交易中的应用

**危险信号：**
- 你只看支持你策略的回测结果，不看失败的案例
- 你听到有人说这个策略有效就很开心，听到有人说不行就很反感
- 你开始找理由说服自己"这个例外没关系"

### 怎么做？

**主动寻找反面证据。**

- 这个策略在什么情况下会亏钱？
- 有没有人用同样的策略亏了钱？为什么？
- 如果我是空头，我会怎么攻击这个策略？
- 我是不是因为投入了太多感情，所以不愿意承认它不行？

**达里欧说："不要问自己'我对不对'，要问'我怎么知道我是对的'。"**

## 奥卡姆剃刀

### 核心
如无必要，勿增实体。越简单的解释，越可能是对的。

### 在交易中的应用

**问题：这个信号是真的有效，还是你在噪声里找规律？**

- 一个 3 行的规则策略，如果效果和 100 行的 ML 模型差不多，选哪个？→ 选简单的
- 为什么？因为简单的更稳定、更可解释、更容易维护
- 复杂的模型，一个参数调错就全崩了

### 简单 vs 复杂

- 简单的策略，逻辑清晰，你知道它什么时候会失效
- 复杂的模型，你自己都不知道它在做什么，出了问题都不知道怎么查

**顶级机构也不是越复杂越好——很多核心策略仍然是简单的统计模型。**

## 思维模型检查清单

做关键交易决策前，过一遍：

- [ ] 我从第一性原理推导过这个策略的逻辑吗？
- [ ] 我用逆向思维想过它怎么会死吗？
- [ ] 我是用概率思考的，还是在赌确定性？
- [ ] 这个真的在我的能力圈内吗？
- [ ] 我留了足够的安全边际吗？
- [ ] 我想过二阶效应了吗？
- [ ] 这是最好的机会吗？还是有更好的选择？
- [ ] 我是不是在犯确认偏误？
- [ ] 有没有更简单的方法？
- [ ] 我从系统整体看了这个问题吗？还是只看了单个指标？
- [ ] 这个代码有没有前视偏差？
- [ ] 这个实验可复现吗？
