## 为什么过拟合是最大敌人

### 第一性原理

**过拟合的本质是什么？**
> 你在历史数据中找到了一个"规律"，但这个规律只是噪声的巧合。
> 你把噪声当成了信号。

**为什么量化交易特别容易过拟合？**
1. **数据量大**：你有几十年的分钟级数据，总能找到某种模式
2. **参数多**：一个策略有10个参数，每个参数10种取值，就是100亿种组合
3. **选择偏差**：你试了100个策略，只报告最好的那一个
4. **非平稳性**：市场是变化的，历史规律不代表未来

### 过拟合的代价

- 回测 Sharpe 2.0 → 实盘 Sharpe 0.2
- 回测最大回撤 5% → 实盘最大回撤 30%
- 你以为是 Alpha，其实是运气

## 三重验证体系

任何策略上线前，必须通过三重验证：

```
PBO（概率回测过拟合）< 0.3
    AND
CPCV（组合交叉验证）样本外有效
    AND
Deflated Sharpe > 0（统计上显著为正）
```

三者缺一不可。只通过一个不算数。

## PBO：概率回测过拟合

### 什么是 PBO

PBO（Probability of Backtest Overfitting）是衡量"你选的策略在样本外表现不如样本内中位数"的概率。

- PBO = 0.1：10% 概率过拟合（很好）
- PBO = 0.3：30% 概率过拟合（可接受）
- PBO = 0.5：50% 概率过拟合（危险）
- PBO = 0.8：80% 概率过拟合（几乎肯定过拟合）

### 计算步骤

1. 把数据集分成 N 个子样本（比如 16 个）
2. 组合成 S = 2^(N-1) 种训练/测试划分
3. 对每种划分，在训练集上选最优策略，在测试集上看表现
4. 统计：测试集上表现排在后 50% 的比例 = PBO

### 实战阈值

- **PBO < 0.2**：优秀，过拟合风险低
- **0.2 ≤ PBO < 0.3**：可接受，上线后密切监控
- **0.3 ≤ PBO < 0.5**：危险，需要简化策略或增加样本
- **PBO ≥ 0.5**：几乎肯定过拟合，不要上线

## CPCV：组合交叉验证

### 为什么普通 K-Fold 不够

普通 K-Fold 交叉验证有两个致命问题：
1. **信息泄露**：训练集和测试集在时间上重叠，未来信息泄露到过去
2. **独立性假设**：金融数据不是独立同分布的，相邻样本高度相关

### CPCV 是什么

CPCV（Combinatorial Purged Cross-Validation）是 López de Prado 提出的方法：

1. **Purge（清除）**：训练集和测试集之间留一段"缓冲区"，避免信息泄露
2. **Embargo（禁运）**：测试集前后各留一段禁运区
3. **Combinatorial（组合）**：所有可能的训练/测试组合都试一遍

### 与普通 K-Fold 的区别

| 维度 | 普通 K-Fold | CPCV |
|------|------------|------|
| 时间顺序 | 随机打乱 | 严格保持时间顺序 |
| 信息泄露 | 有 | 无（purge + embargo） |
| 验证次数 | K 次 | 2^(N-1) 次 |
| 结果稳定性 | 波动大 | 更可靠 |

## Deflated Sharpe Ratio

### 为什么需要 Deflated Sharpe

普通 Sharpe Ratio 有个问题：**你试的策略越多，最好的那个 Sharpe 天然就越高**。

这就像掷硬币：你掷 1000 个人，总有几个人连续掷出 10 次正面。不是他们有超能力，是概率。

Deflated Sharpe Ratio 就是把这个"试验次数带来的虚高"校正掉。

### 计算公式

```
DSR = (SR_observed - SR_expected_max) × √(N-1) / √(1 - skew×SR + (kurt-1)/4×SR²)
```

- `SR_observed`：你观察到的 Sharpe
- `SR_expected_max`：如果你试了 N 个策略，纯靠运气能达到的最大 Sharpe 的期望值
- `skew`：收益的偏度
- `kurt`：收益的峰度

### 解读

- **DSR > 2**：高度显著，策略真的有 Alpha
- **1 < DSR < 2**：显著，策略可能有 Alpha
- **0 < DSR < 1**：不显著，可能只是运气
- **DSR < 0**：肯定是过拟合

## 决策规则冻结

### 什么是决策规则冻结

**在做实验之前，就定好什么结果算"成功"，什么结果算"失败"。实验做完后，不能改标准。**

### 为什么重要

如果你实验后再定标准，你会不自觉地"调整"标准来匹配结果——这就是确认偏误。

### 冻结清单

实验前必须冻结：
1. **评估指标**：用 Sharpe 还是 Calmar？主指标是什么？
2. **成功阈值**：Sharpe > 1.5 才算成功？
3. **样本期**：用哪段数据做训练，哪段做测试？
4. **参数范围**：参数搜索的边界在哪里？
5. **试验次数上限**：最多试多少组参数？

## trials 计数原则

### 什么是 trials 计数

**trials = 你试过的所有策略数量，包括失败的。**

不是只算"最终选出来的那个"，是算你在搜索过程中试过的每一个。

### 为什么重要

计算 Deflated Sharpe 的时候，trials 数量是关键参数。你试的越多，需要校正得越多。

### 常见错误

❌ 错误：我试了 1 个策略，Sharpe 1.8，DSR = 显著
✅ 正确：我试了 100 个策略，选了最好的那个 Sharpe 1.8，DSR = 不显著

**你试了多少次，就诚实报告多少次。**

## 过拟合诊断清单

策略上线前，过一遍这个清单：

- [ ] 这个策略的逻辑是什么？（不是"回测好看"，是为什么有效）
- [ ] 这个 Alpha 为什么存在？（行为偏差？结构红利？信息优势？）
- [ ] 这个 Alpha 为什么没被套利掉？
- [ ] 这个 Alpha 什么时候会消失？
- [ ] PBO 是多少？< 0.3 吗？
- [ ] CPCV 样本外表现和样本内差多少？衰减 < 30% 吗？
- [ ] Deflated Sharpe 是多少？> 1 吗？
- [ ] 我一共试了多少个策略？（包括失败的）
- [ ] 我是先定好规则再实验，还是先看结果再定规则？
- [ ] 参数有多少个？参数越多越容易过拟合
- [ ] 回测是不是只在一段行情好的数据上做的？
- [ ] 这个策略在不同市场状态下都有效吗？（牛市/熊市/震荡市）

任何一项答不上来，就不要上线。
