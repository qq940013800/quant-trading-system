## 策略分类框架

### 按 Alpha 来源分类

| 策略类型 | 赚什么钱 | 逻辑基础 | 容量 | 机构采用度 |
|---------|---------|---------|------|-----------|
| **趋势跟踪 / CTA** | 行为偏差（羊群效应、处置效应） | 趋势会自我延续 | 高 | ★★★★★ |
| **海龟交易法** | 行为偏差 | 突破后趋势延续 | 中-高 | ★★★★☆ |
| **价格行为 / K线形态** | 行为偏差 + 统计偏差 | 特定形态后概率占优 | 低 | ★★☆☆☆ |
| **供需区交易** | 结构红利 + 行为偏差 | 机构挂单形成的供需缺口 | 低 | ★★☆☆☆ |
| **机构订单原理 (Order Block)** | 信息优势（推断） | 机构建仓留下的痕迹 | 低 | ★☆☆☆☆ |
| **ICT 方法论** | 结构红利 + 行为偏差 | 流动性猎杀 + 算法交易模式 | 低 | ★☆☆☆☆ |
| **流动性猎杀** | 结构红利 | 止损单堆积处是流动性池 | 低 | ★★★☆☆ |

**重要声明**：
- ★★★★★ = 顶级机构大规模采用，有学术和数据支持
- ★★★☆☆ = 有逻辑但主要在散户圈流行，机构用类似逻辑但方法更严谨
- ★☆☆☆☆ = 散户圈流行，缺乏严格统计验证，存在后验偏差

## 趋势跟踪类策略

### 核心逻辑

**趋势是怎么形成的？**
1. 信息逐步扩散（不是所有人同时知道）
2. 羊群效应（看到涨了才跟进）
3. 处置效应（赚一点就跑，导致价格反弹后继续走）
4. 止损连锁反应（跌破关键位触发大量止损，加速趋势）

**趋势跟踪赚的就是这个过程的钱。**

### CTA（Commodity Trading Advisor）

#### 第一性拆解
- **Alpha 来源**：行为偏差 + 趋势惯性
- **赚什么钱**：在趋势形成早期进场，在趋势衰竭时出场
- **核心指标**：趋势强度（ADX、线性回归斜率）、突破幅度、波动率

#### 经典 CTA 策略框架
1. **动量信号**：过去 N 个月收益率排名，做多强势、做空弱势
2. **突破信号**：唐奇安通道突破（20 日 / 55 日高低点）
3. **波动率调整**：ATR 调整仓位，波动大就少配
4. **分散化**：跨多个品种（商品、股指、债券、外汇）

#### 失效条件
- 震荡市（反复假突破，连续止损）
- 趋势太短（进场就反转）
- 拥挤（太多人做同样的 CTA，收益衰减）

### 海龟交易法

#### 第一性拆解
- **Alpha 来源**：突破后的趋势延续效应
- **核心规则**：
  - 入场：20 日最高价突破（做多）/ 10 日最低价突破（做空）
  - 止损：2×ATR 反向
  - 加仓：每涨 0.5×ATR 加一次仓，最多加 4 次
  - 出场：10 日最低价反转（做多）/ 20 日最高价反转（做空）

#### 为什么有效？
- 不预测，只跟随——减少主观判断错误
- 严格的仓位管理——亏的时候小亏，赚的时候大赚
- 分散到多个品种——提高胜率的稳定性

#### 常见误用
- ❌ 在震荡市机械执行——连续止损到怀疑人生
- ❌ 不加过滤器——什么市场都做
- ❌ 止损太宽——小亏拖成大亏

### SMA 交叉 / 三位一体

#### SMA 交叉的本质
- 金叉（短期均线上穿长期均线）= 趋势向上的确认信号
- 死叉 = 趋势向下
- **问题**：均线是滞后指标——金叉出现的时候，趋势已经走了一段了

#### "三位一体"是什么？
- 通常指：均线趋势方向 + MACD 动量确认 + K线形态入场
- 本质是：用多个独立信号互相确认，减少假信号

#### 第一性评估
- ✅ 优点：简单、客观、可回测
- ❌ 缺点：滞后、震荡市频繁打脸
- **正确用法**：不是直接用金叉死叉交易，而是用它来判断大趋势方向，只做顺势的交易

### 趋势跟踪的统一原则

1. **截断亏损，让利润奔跑**——这是趋势跟踪的灵魂
2. **不预测顶底**——只跟随，不猜
3. **分散到多个品种**——单一策略在单一品种上会失效
4. **接受低胜率**——趋势跟踪通常胜率只有 35~45%，靠盈亏比赚钱
5. **过滤器**：只在 ADX > 25 的强趋势市场做，震荡市不做

## 价格行为类策略

### 核心逻辑

价格行为（Price Action）认为：
- 所有信息都已经反映在价格里了
- 关键是观察价格本身的形态和结构
- 不需要指标，只看 K线和价格位置

### K线形态（吞没、锤子线、十字星等）

#### 第一性拆解
- **Alpha 来源**：行为偏差（散户情绪在 K线上的体现）
- **逻辑**：特定的 K线组合反映了多空力量的突然转换

#### 常见形态的本质

| 形态 | 本质 | 可靠性 |
|------|------|--------|
| **看涨吞没** | 空头力量耗尽，多头突然反转 | 中等（在支撑位更可靠） |
| **看跌吞没** | 多头力量耗尽，空头突然反转 | 中等（在阻力位更可靠） |
| **锤子线** | 下探后拉回，下方有买盘 | 中等 |
| **射击之星** | 上冲后回落，上方有卖压 | 中等 |
| **十字星** | 多空平衡，犹豫状态 | 低（需要后续确认） |

#### 重要提醒
- K线形态的统计可靠性远低于散户想象
- 同一个形态，在支撑位和在中间位置，胜率完全不同
- **位置比形态重要 10 倍**——在关键支撑/阻力位的吞没，比随便一个位置的吞没有用得多

### 突破交易

#### 突破的本质
- 价格突破关键位（前高、前低、震荡区间边界）
- 突破后，趋势加速

#### 为什么突破有效？
1. 突破关键位 → 触发止损单 → 推动价格继续走
2. 突破确认趋势 → 趋势跟踪者进场 → 进一步推动
3. 心理效应 → "突破了，趋势来了" → 更多人跟进

#### 真假突破的区别
- **真突破**：放量、收盘站稳、回踩不破
- **假突破**：缩量、突破后立刻回来、插针式突破

#### 过滤器
- 要求突破时成交量放大
- 要求收盘价突破（不是盘中插针）
- 等回踩确认再进场（牺牲一点利润，换更高胜率）

## 供需与机构订单类策略

### 供需区（Supply/Demand Zones）

#### 核心逻辑
- 价格快速离开的区域 = 供需不平衡的区域
- 买方区（需求区）：价格从这里快速上涨 → 说明这里有大量买单
- 卖方区（供给区）：价格从这里快速下跌 → 说明这里有大量卖单

#### 第一性拆解
- **Alpha 来源**：结构红利（机构挂单留下的痕迹）
- **为什么有效**：
  1. 机构建仓不可能一天完成，会在关键位置反复挂单
  2. 价格回到供需区，相当于回到机构的成本区
  3. 机构有动力维护自己的仓位 → 价格再次反弹

#### 常见应用
- 价格回到需求区 + 看涨吞没 → 做多
- 价格回到供给区 + 看跌吞没 → 做空

#### 供需区吞没 / 供需区突破
- **供需区吞没**：价格进入供需区后，出现强力的反转 K线形态 → 确认供需区有效
- **供需区突破**：价格强力穿过供需区 → 说明这个供需区失效了，不要再用它做反转

#### 诚实评估
- ✅ 有逻辑基础——机构确实会在关键位置挂单
- ⚠️ 但散户画的供需区往往很主观——同一个图，不同人画的位置不一样
- ⚠️ 缺乏严格的大样本统计验证
- ⚠️ 很多是"事后看图说话"——回头看都对，实盘做就错

### 机构订单原理（Order Block）

#### 核心逻辑
- Order Block = 机构建仓的那根 K线
- 看涨 Order Block：一根大阳线之前的最后一根阴线 → 机构在阴线位置建多仓
- 看跌 Order Block：一根大阴线之前的最后一根阳线 → 机构在阳线位置建空仓

#### 第一性评估
- 理论上有道理——机构确实是分批建仓的
- 但问题是：你怎么知道那根 K线是机构建仓，而不是散户交易？
- 本质上是一种"事后归因"——涨了，之前那根阴线就是 Order Block；跌了，之前那根阳线就是 Order Block

## ICT 方法论

### ICT 是什么？
ICT（Inner Circle Trader）是一套散户圈非常流行的交易方法论，包含：
- 流动性猎杀（Liquidity Hunt）
- 订单块（Order Block）
- 公平价值缺口（FVG / Imbalance）
- 双重顶/底的流动性
- 日内关键时间窗口

### 第一性拆解

#### 合理的部分
1. **流动性是真实存在的**：止损单确实会堆积在关键位
2. **算法交易确实有模式**：做市商和大型算法确实会猎杀流动性
3. **关键时间窗口有逻辑**：伦敦开盘、纽约开盘确实交易量更大

#### 有争议的部分
1. **"机构在猎杀你的止损"**：部分正确——流动性是客观存在的，但不是专门针对你
2. **精确到分钟的时间窗口**：更多是统计巧合，不是铁律
3. **各种神秘的图形结构**：有事后解读的成分

### ICT 的核心概念：流动性猎杀

见下一节。

## 流动性猎杀

### 什么是流动性猎杀？

**核心洞察**：
- 止损单不是随机分布的——它们堆积在明显的关键位（前高、前低、整数关口）
- 这些止损单就是"流动性池"
- 大资金要建仓，需要对手盘——这些止损单就是现成的对手盘
- 所以价格会先穿过关键位，扫掉止损单，然后反转

### 第一性拆解
- **Alpha 来源**：结构红利（市场微观结构的必然结果）
- **为什么有效**：
  1. 止损单确实堆积在关键位
  2. 大资金确实需要流动性来建仓
  3. 扫完止损后，卖压/买压消失，价格反转

### 常见模式
1. **假突破（False Breakout）**：价格突破前高，扫掉上方止损，然后跌回来
2. **插针（Stop Run）**：盘中快速刺破关键位，收盘又回来
3. **流动性抓取（Liquidity Grab）**：价格故意打到止损密集区，然后反转

### 实战应用
- 在明显的前高/前低位置，警惕假突破
- 如果突破后快速收回，反而可以做反转
- 结合成交量——放量突破是真突破，缩量插针是假突破

### 诚实评估
- ✅ 逻辑成立——流动性猎杀是真实的市场现象
- ✅ 有学术研究支持（关于订单流和止损单分布）
- ⚠️ 但不是每次突破都是猎杀——有时候就是真突破
- ⚠️ 散户容易过度拟合——把每次反转都解释成"流动性猎杀"

## 市场识别与趋势判断框架

### 为什么需要市场识别？

**核心原则：不同市场状态，用不同策略。**
- 趋势市 → 做趋势跟踪
- 震荡市 → 做均值回归 / 区间交易
- 拐点市 → 谨慎，等确认

### 市场状态判断工具

#### 1. 用均线判断
- 价格在均线上方 + 均线向上 = 上升趋势
- 价格在均线下方 + 均线向下 = 下降趋势
- 价格在均线上下穿梭 + 均线走平 = 震荡

#### 2. 用 ADX 判断趋势强度
- ADX > 25：强趋势市
- ADX < 20：震荡市
- ADX 20~25：过渡区，谨慎

#### 3. 用高低点结构判断
- 上升趋势：高点越来越高，低点越来越高
- 下降趋势：高点越来越低，低点越来越低
- 震荡：高低点没有明显方向

#### 4. 用波动率判断
- 波动率持续扩大 = 趋势可能在形成
- 波动率持续收缩 = 可能在酝酿大行情（布林带收口）

### 趋势判断的多时间框架原则

**大周期定方向，小周期找入场点。**

- 日线：大趋势方向（只做多 or 只做空）
- 4小时：回调位置
- 1小时 / 15分钟：具体入场点

**不要逆大周期的趋势做单。**

## 策略组合与过滤器

### 为什么单一策略不够？

没有任何一个策略在所有市场环境下都有效。你需要：
1. 不同类型的策略组合（趋势 + 均值回归 + 套利）
2. 每个策略加过滤器，只在适合的市场环境下启用

### 常见过滤器

#### 1. 趋势过滤器
- 用 ADX 或均线判断是否是趋势市
- 趋势市 → 启用趋势跟踪策略
- 震荡市 → 关闭趋势策略

#### 2. 波动率过滤器
- 波动率太低 → 可能没什么机会
- 波动率太高 → 风险大，降低仓位

#### 3. 时间过滤器
- 只在特定时间段交易（比如伦敦开盘 + 纽约开盘）
- 避开低流动性的时段

#### 4. 位置过滤器
- 只在关键支撑/阻力位附近交易
- 不在中间位置追单

### 策略组合的例子

| 市场状态 | 启用策略 | 关闭策略 |
|---------|---------|---------|
| 强趋势市（ADX > 25） | 海龟突破、SMA 趋势跟随 | 均值回归、区间交易 |
| 震荡市（ADX < 20） | 区间高抛低吸、均值回归 | 趋势跟踪、突破交易 |
| 拐点/不确定 | 降低仓位、观望 | 所有激进策略 |

## 散户常见误区

### ❌ 误区 1：形态万能论
"出现吞没就买，出现十字星就卖"
→ 错。位置比形态重要，市场状态比形态重要。同一个形态，在不同环境下胜率天差地别。

### ❌ 误区 2：指标越多越好
均线 + MACD + RSI + KDJ + 布林带 + ...
→ 错。很多指标是高度相关的——加了 5 个指标，本质上还是在看同一件事。

### ❌ 误区 3：圣杯心态
"找到那个完美的策略，就能稳定赚钱"
→ 错。没有圣杯。稳定盈利来自：合理的仓位管理 + 严格的风控 + 多个策略组合 + 持续迭代。

### ❌ 误区 4：事后看图说话
"你看这个图，这个位置明显是供需区，这里入场就赚了"
→ 错。回头看都对。实盘的时候，你不知道哪个供需区会有效，哪个会被打穿。

### ❌ 误区 5：忽视交易成本
回测里不考虑滑点和手续费，看起来 Sharpe 很高
→ 实盘一做，交易成本吃掉一半利润。高频策略尤其要注意。

### ❌ 误区 6：过度拟合
在历史数据上把参数调到完美
→ 样本外就废了。简单、鲁棒的策略，比复杂、精致的策略更持久。

## 策略评估检查清单

每次考虑用一个新策略，过一遍：

- [ ] 这个策略赚的是什么钱？（Alpha 来源是什么？）
- [ ] 这个 Alpha 为什么存在？逻辑上说得通吗？
- [ ] 这个策略在什么市场环境下有效？什么环境下失效？
- [ ] 平均胜率和盈亏比大概是多少？期望值是正的吗？
- [ ] 最大回撤可能有多大？我能承受吗？
- [ ] 交易成本扣掉之后，还赚钱吗？
- [ ] 这个策略是不是太复杂了？能不能更简单？
- [ ] 如果这个策略连续亏 5 次，我还能坚持执行吗？
- [ ] 我有没有事后偏差——只是因为历史图上看起来有效才喜欢它？
