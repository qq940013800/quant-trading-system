## 第一性原理

### 为什么需要自动匹配？

**核心事实：没有任何策略在所有市场环境下都有效。**

- 趋势跟踪在震荡市连续止损
- 均值回归在强趋势市被反复打脸
- 做市在波动率飙升时库存爆仓
- 套利在流动性枯竭时无法平仓

**结论**：策略必须和市场状态匹配。不同的市场环境，用不同的策略。

### 第一性推导

1. **市场状态有哪些？** → 趋势市 / 震荡市 / 拐点市 / 危机市
2. **每种状态下什么策略有效？** → 趋势跟踪 / 均值回归 / 观望 / 对冲
3. **怎么判断当前是什么状态？** → 量化指标（ADX、波动率、高低点结构）
4. **怎么自动切换？** → 规则引擎 + 阈值 + 滞后确认

### 自动匹配的目标

不是"选一个策略"，而是：
- **多策略并行**：不同策略同时跑，各赚各的钱
- **动态权重**：根据市场状态调整各策略的仓位占比
- **自动启停**：策略失效就自动降仓，有效就加仓

## 输入维度

### 匹配需要哪些信息？

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  市场状态    │  │  自身条件    │  │  策略库     │
│             │  │             │  │             │
│ · 趋势强度   │  │ · 资金规模   │  │ · 策略列表   │
│ · 波动率水平  │  │ · 风险偏好   │  │ · 各策略参数 │
│ · 流动性状况  │  │ · 时间周期   │  │ · 历史表现   │
│ · 品种特性   │  │ · 技术能力   │  │ · 容量上限   │
└─────────────┘  └─────────────┘  └─────────────┘
         ↓              ↓              ↓
         └──────────────┼──────────────┘
                        ↓
              ┌─────────────────┐
              │  策略匹配引擎    │
              │  输出：最优组合   │
              └─────────────────┘
```

### 维度 1：市场状态

| 指标 | 计算方法 | 判断阈值 |
|------|---------|---------|
| **趋势强度** | ADX (14) | > 25 = 强趋势；< 20 = 无趋势 |
| **波动率水平** | ATR(14) / 价格 | 历史分位数：高/中/低 |
| **高低点结构** | 近 20 日高点/低点序列 | 高点更高+低点更高 = 上升趋势；反之下降；无序 = 震荡 |
| **流动性** | 日均成交量、买卖价差 | 充足/一般/匮乏 |
| **市场情绪** | VIX、恐慌指数 | 恐慌/中性/贪婪 |

### 维度 2：自身条件

| 维度 | 选项 |
|------|------|
| **资金规模** | < 100万 / 100万~1000万 / > 1000万 |
| **风险偏好** | 保守（最大回撤 < 10%）/ 平衡（15%）/ 激进（25%+） |
| **交易频率** | 高频（日内）/ 中频（日周）/ 低频（月季） |
| **技术能力** | 手动交易 / 简单自动化 / 完整量化系统 |

### 维度 3：策略库

每个策略需要记录：
- 适用市场状态（趋势/震荡/危机）
- 历史表现（Sharpe、最大回撤、胜率、盈亏比）
- 容量上限（多少资金会影响收益）
- 所需技术门槛
- 与其他策略的相关性

## 市场状态识别引擎

### 四级市场状态分类

```
┌─────────────────────────────────────────────────┐
│                 市场状态识别矩阵                  │
├───────────────┬───────────────┬─────────────────┤
│   趋势强度    │   波动率      │    市场状态     │
├───────────────┼───────────────┼─────────────────┤
│  强 (ADX>25)  │  低-中        │  趋势市         │
│  强 (ADX>25)  │  高           │  趋势加速市     │
│  弱 (ADX<20)  │  低           │  震荡市         │
│  弱 (ADX<20)  │  高           │  拐点/危机市    │
│  中 (20~25)   │  任意         │  过渡区         │
└───────────────┴───────────────┴─────────────────┘
```

### 状态判定规则

1. **趋势市**：
   - ADX > 25 且持续 3 根 K 线以上
   - 高低点结构明确（高点更高 + 低点更高，或反之）
   - → 启用趋势跟踪类策略

2. **震荡市**：
   - ADX < 20 且持续 5 根 K 线以上
   - 价格在区间内来回穿梭
   - → 启用均值回归类策略

3. **拐点/危机市**：
   - 波动率突然飙升（ATR 是过去 20 日均值的 2 倍以上）
   - 价格剧烈波动，方向不明
   - → 降仓观望，启用对冲策略

4. **过渡区**：
   - 指标不明确，方向不明
   - → 降低仓位，不要重仓赌方向

### 滞后确认原则

**不要追着指标跑。** 状态切换需要确认：
- 趋势确认：ADX 连续 3 根 K 线 > 25
- 震荡确认：ADX 连续 5 根 K 线 < 20
- 这样避免假信号导致的频繁切换

## 策略匹配决策树

### 第一步：根据市场状态筛选

```
当前是什么市场状态？
  ├─ 趋势市
  │    → 启用：趋势跟踪、海龟突破、动量策略
  │    → 禁用：均值回归、反转策略
  │
  ├─ 震荡市
  │    → 启用：均值回归、区间交易、做市
  │    → 禁用：趋势跟踪、突破策略
  │
  ├─ 拐点/危机市
  │    → 启用：对冲、尾部保护
  │    → 禁用：所有方向性策略
  │
  └─ 过渡区
       → 降低总仓位，观望为主
```

### 第二步：根据资金规模过滤

| 资金规模 | 适合的策略 | 不适合的策略 |
|---------|-----------|------------|
| < 100万 | CTA 趋势跟踪、因子投资、手动价格行为 | 高频做市、套利（容量太小） |
| 100万~1000万 | 统计套利、均值回归、事件驱动 | 极端低延迟（成本太高） |
| > 1000万 | 多策略组合、做市、另类数据 | 单一策略（容量不够） |

### 第三步：根据风险偏好调整

| 风险偏好 | 仓位调整 | 策略选择 |
|---------|---------|---------|
| 保守 | 总仓位 30%~50% | 低波动策略、分散化、严格止损 |
| 平衡 | 总仓位 50%~80% | 中等波动、多策略组合 |
| 激进 | 总仓位 80%~100% | 高波动策略、集中持仓 |

### 第四步：组合优化

从筛选后的策略中，选择相关性最低的组合：
- 趋势跟踪 + 均值回归（天然对冲）
- 股票多头 + 波动率对冲
- 国内资产 + 海外资产

## 策略组合优化

### 核心原则：风险分散

**不是选"最好的策略"，是选"最互补的策略组合"。**

### 策略相关性矩阵示例

|          | 趋势跟踪 | 均值回归 | 做市 | 套利 |
|----------|---------|---------|------|------|
| 趋势跟踪 | 1.0     | -0.3    | 0.1  | 0.0  |
| 均值回归 | -0.3    | 1.0     | 0.2  | 0.1  |
| 做市     | 0.1     | 0.2     | 1.0  | 0.3  |
| 套利     | 0.0     | 0.1     | 0.3  | 1.0  |

→ 最优组合：趋势跟踪 + 均值回归 + 做市（低相关，分散化）

### 权重分配方法

#### 方法 1：等风险分配
- 每个策略贡献相等的风险
- 波动大的策略少配资金，波动小的多配

#### 方法 2：按历史 Sharpe 分配
- 历史 Sharpe 越高，权重越大
- 权重 ∝ Sharpe²

#### 方法 3：核心-卫星
- **核心（70%~80%）**：低波动、稳定的策略（因子投资、宏观趋势）
- **卫星（20%~30%）**：高波动、高收益的策略（短线交易、事件驱动）

## 动态切换机制

### 什么时候切换？

**触发条件（满足任一）：**
1. 市场状态发生变化（趋势 → 震荡，或反之）
2. 某策略连续 N 次亏损（说明当前环境不适合它）
3. 某策略的回撤超过阈值

### 怎么切换？

**渐进式切换，不要一键全换：**
- 旧策略仓位逐步降低（比如每次交易减 20%）
- 新策略仓位逐步增加
- 过渡期 3~5 个交易日

### 切换的滞后与确认

**不要因为一天的数据就切换。**
- 趋势市确认：ADX 连续 3 根 K 线 > 25
- 震荡市确认：ADX 连续 5 根 K 线 < 20
- 避免假信号导致的频繁切换和过度交易

### 防抖动设计

**问题**：指标在阈值附近来回震荡，导致策略频繁切换。

**解决方案：滞回阈值**
- 从趋势切震荡：ADX < 18（比正常阈值 20 更低）
- 从震荡切趋势：ADX > 25（比正常阈值 25 更高）
- → 中间有个缓冲带，不会来回跳

## 实战示例

### 场景 1：XAU/USD，日线

**市场状态识别：**
- ADX(14) = 32 → 强趋势市
- ATR = 18 美元，处于历史 60% 分位 → 中等波动率
- 近 20 日：高点越来越高，低点越来越高 → 明确上升趋势

**匹配结果：**
- ✅ 启用：海龟突破（20 日新高入场）、趋势跟踪均线策略
- ❌ 禁用：均值回归、反转策略
- 仓位：平衡型风险偏好 → 单笔风险 1%，总仓位 60%

### 场景 2：EUR/USD，4小时线

**市场状态识别：**
- ADX(14) = 16 → 无趋势（震荡）
- ATR = 50 点，处于历史 30% 分位 → 低波动率
- 价格在 1.0850~1.0950 区间来回穿梭

**匹配结果：**
- ✅ 启用：区间高抛低吸、均值回归策略
- ❌ 禁用：趋势跟踪、突破策略
- 仓位：震荡市不确定性高 → 降低到总仓位 40%

### 场景 3：波动率飙升（VIX > 30）

**市场状态识别：**
- 波动率是过去 20 日均值的 3 倍
- 价格剧烈波动，方向不明
- → 拐点/危机市

**匹配结果：**
- ✅ 启用：尾部对冲（虚值 put）、降低仓位
- ❌ 禁用：所有方向性策略
- 仓位：总仓位降到 20% 以下，保住本金

## 常见误区

### ❌ 误区 1：找一个"万能策略"
**真相**：不存在万能策略。不同市场环境需要不同策略。

### ❌ 误区 2：策略越多越好
**真相**：10 个高度相关的策略 = 1 个策略。要低相关的策略组合。

### ❌ 误区 3：指标一变就切换
**真相**：频繁切换 = 频繁交易 = 手续费吃掉利润。要有滞后确认和滞回阈值。

### ❌ 误区 4：只看历史表现选策略
**真相**：历史 Sharpe 高不代表未来有效。要考虑策略逻辑是否还成立、是否拥挤。

### ❌ 误区 5：自动匹配 = 无人值守
**真相**：自动匹配是辅助决策，不是替代判断。异常情况需要人工介入。

## 匹配模块检查清单

每次策略调整前，过一遍：

- [ ] 当前市场状态是什么？（趋势/震荡/拐点/过渡）
- [ ] 这个状态下什么策略有效？什么策略会亏钱？
- [ ] 各策略之间相关性高吗？是真分散还是伪分散？
- [ ] 权重分配合理吗？波动大的策略是不是配太多了？
- [ ] 切换有没有滞后确认？会不会因为假信号频繁切换？
- [ ] 总仓位和我的风险偏好匹配吗？
- [ ] 策略容量够吗？我的资金会不会影响策略收益？
