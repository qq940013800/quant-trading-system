## 总览

### 交易系统完整闭环

```
市场状态诊断 → 策略匹配 → 入场信号 → 仓位止损 → 持仓管理 → 复盘迭代
     ↑                                                          ↓
     └────────────────────  反馈循环  ──────────────────────────┘
```

### 核心原则（按优先级排序）

1. **生存第一**：先不亏钱，再谈赚钱
2. **截断亏损**：小亏是成本，大亏是灾难
3. **让利润奔跑**：抓住大趋势，覆盖所有小亏损
4. **概率思维**：不追求每次都对，追求长期期望值为正
5. **一致性**：同样的情况做同样的决策，不情绪化

## 第一步：市场状态诊断

### 诊断清单（30秒完成）

**1. 大周期趋势是什么？**
- [ ] 上升趋势？（高点更高 + 低点更高）
- [ ] 下降趋势？（高点更低 + 低点更低）
- [ ] 震荡市？（高低点不创新）

**2. 趋势强度如何？**
- [ ] 强趋势（角度陡、回调浅、连续创新高/低）
- [ ] 中等趋势（有回调，但不破前高/低）
- [ ] 弱趋势（角度平缓、经常横盘）

**3. 波动率水平？**
- [ ] 高波动（ATR 处于历史高位）
- [ ] 正常波动
- [ ] 低波动（布林带收窄，可能要突破）

**4. 现在在趋势的哪个阶段？**
- [ ] 积累期（底部/顶部，没人关注）
- [ ] 参与期（趋势明确，大众入场）
- [ ] 派发期（所有人都在谈，可能要反转）

## 第二步：策略选择与匹配

### 策略匹配决策树

```
当前市场状态？
  │
  ├─ 强趋势市
  │    ├─ 上升 → 趋势跟踪（回调做多）
  │    └─ 下降 → 趋势跟踪（反弹做空）
  │
  ├─ 震荡市
  │    ├─ 区间清晰 → 区间交易（高抛低吸）
  │    └─ 区间模糊 → 观望
  │
  ├─ 拐点/危机市
  │    ├─ 极端超买超卖 → 反转交易（小仓位试错）
  │    └─ 方向不明 → 降仓观望
  │
  └─ 低波动盘整
       └─ 准备突破（等突破信号）
```

### 策略选择对照表

| 市场状态 | 首选策略 | 禁用策略 | 仓位建议 |
|---------|---------|---------|---------|
| 强上升趋势 | 趋势跟踪、回调买入 | 抄顶做空 | 正常仓位 |
| 强下降趋势 | 趋势跟踪、反弹做空 | 抄底做多 | 正常仓位 |
| 震荡市 | 区间高抛低吸 | 趋势跟踪、追突破 | 降低仓位 |
| 拐点市 | 反转试错（小仓位） | 重仓追方向 | 半仓以下 |
| 低波动 | 等待突破 | 频繁交易 | 轻仓或空仓 |

## 第三步：入场信号确认

### 入场检查清单

**大周期方向确认：**
- [ ] 大周期（日线）方向和我想做的方向一致？
- [ ] 现在不是在关键位的对面？

**位置确认：**
- [ ] 入场位置在支撑/阻力位附近？
- [ ] 盈亏比至少 1:2？

**信号确认（至少2个共振）：**
- [ ] K线形态确认（吞没/Pin Bar/锤子线）
- [ ] 指标确认（RSI超买超卖/背离）
- [ ] 成交量确认（放量配合）
- [ ] 结构确认（BOS/CHoCH）

**突破真假判断：**
- [ ] 收盘价突破（不是盘中插针）
- [ ] 放量突破（不是缩量假突破）
- [ ] 突破后不回头（不是扫止损）

## 第四步：仓位与止损计算

### 固定 R 倍数法（推荐）

**公式：**
```
单笔风险金额 = 总资金 × 1%
止损距离 = 入场价 - 止损价
仓位 = 单笔风险金额 / 止损距离
```

**示例：**
- 总资金：10万
- 单笔风险：1% = 1000元
- 入场价：100元
- 止损价：98元（止损距离 2%）
- → 仓位 = 1000 / 2% = 5万元

### 止损位置选择

| 策略类型 | 止损位置 |
|---------|---------|
| 趋势跟踪 | 前低/前高之外 |
| 突破交易 | 突破位回踩失败的位置 |
| 区间交易 | 区间边界之外 |
| 反转交易 | 反转K线的高点/低点之外 |

### 仓位调整规则

| 情况 | 仓位调整 |
|------|---------|
| 胜率高、信号强 | 正常仓位（1%风险） |
| 信号一般 | 半仓（0.5%风险） |
| 连续亏2次 | 减半仓 |
| 连续亏3次 | 暂停交易1天 |
| 单日亏损达 3% | 当天停止交易 |

## 第五步：执行与持仓管理

### 入场后做什么？

**第一步：立刻设好止损**
- 入场的同时就设好止损单
- 不要等"看看再说"

**第二步：设定目标（可选）**
- 第一目标：1:1 R（可以先平一半）
- 第二目标：1:2 R（移动止损到成本）
- 第三目标：让利润奔跑（跟踪止盈）

**第三步：持仓中不频繁操作**
- 不要因为一点波动就慌
- 只要没到止损，就拿着
- 不要提前止盈（截断利润是大忌）

### 移动止损规则

**盈利后怎么移动止损？**

```
盈利 1R → 止损移到入场价（保本）
盈利 2R → 止损移到 1R 的位置
盈利 3R → 用跟踪止盈（比如回撤 2×ATR 就走）
```

**核心思想：** 让亏损单真的亏小，让盈利单尽量赚大。

## 第六步：复盘与迭代

### 每笔交易后复盘

**这笔交易做对了什么？**
- [ ] 遵守交易规则了吗？
- [ ] 入场位置合理吗？
- [ ] 止损设对了吗？

**这笔交易做错了什么？**
- [ ] 有没有情绪化交易？
- [ ] 有没有提前止盈/死扛亏损？
- [ ] 有没有过度交易？

**下次怎么改进？**
- [ ] 记录下来，下次避免

### 每周复盘

- [ ] 本周交易胜率多少？
- [ ] 盈亏比多少？
- [ ] 最大回撤多少？
- [ ] 哪些策略有效？哪些无效？
- [ ] 市场环境变了吗？需要调整策略吗？

## 风控红线清单

**以下情况绝对不能做：**

- ❌ 单笔交易风险超过总资金的 2%
- ❌ 没有止损就入场
- ❌ 亏损了加仓摊平成本
- ❌ 盈利了就赶紧跑（截断利润）
- ❌ 连续亏损后加大仓位想翻本
- ❌ 在不明朗的市场重仓赌方向
- ❌ 听消息交易
- ❌ 交易超出自己能力圈的品种

## 失败模式检查

**用逆向思维问自己：怎么做这笔交易一定会亏钱？**

- [ ] 我是不是追高了？（买在山顶）
- [ ] 我是不是抄底了？（接飞刀）
- [ ] 我是不是没设止损？（死扛风险）
- [ ] 我是不是仓位太重？（一次就亏大的）
- [ ] 我是不是在震荡市做趋势？（来回打脸）
- [ ] 我是不是在趋势市抄顶摸底？（逆势）
- [ ] 我是不是情绪化交易？（上头了）

**如果以上有任何一条答案是"是"，那就不要做这笔交易。**
