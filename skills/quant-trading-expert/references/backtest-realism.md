## 回测的真实性问题

### 第一性原理

**回测的本质是什么？**
> 回测 = 用历史数据模拟策略表现。
> 但历史数据里没有"你下单"这个事件。
> 你一下单，就会影响市场价格（市场冲击）。

### 回测与实盘的典型差距

| 指标 | 回测 | 实盘 | 差距原因 |
|------|------|------|---------|
| 年化收益 | 20% | 8% | 滑点、佣金、冲击 |
| Sharpe | 1.5 | 0.6 | 同上 |
| 最大回撤 | 10% | 25% | 跳空、流动性消失 |

**经验法则：回测收益打个 3-5 折，才接近实盘。**

## 滑点模型

### 什么是滑点

**滑点 = 你下单时的预期价格 vs 实际成交价格的差。**

- 你以为能在 100 块买入，实际成交在 100.1 块
- 滑点 = 0.1 块

### 滑点的来源

1. **买卖价差**：你买在 ask，卖在 bid
2. **市场冲击**：你的单子推动了价格
3. **延迟**：信号产生到下单有时间差，价格已经动了

### 滑点模型分级

#### Level 1：固定滑点（最简单）
```
滑点 = 固定值（比如 1 个点）
```
- 优点：简单
- 缺点：不真实——波动大的时候滑点应该更大

#### Level 2：固定百分比
```
滑点 = 价格 × 固定百分比（比如 0.1%）
```
- 优点：比固定值合理
- 缺点：还是太简单

#### Level 3：波动率自适应
```
滑点 = k × ATR
```
- 波动率大的时候（ATR 大），滑点大
- 波动率小的时候，滑点小
- 这是更真实的模型

#### Level 4：基于成交量的冲击模型
```
滑点 = f(订单量, 当时成交量, 波动率)
```
- 你的订单占当时成交量的比例越大，滑点越大
- 这是最真实的模型，但需要数据支持

## 佣金与点差

### 佣金

**佣金 = 经纪商收的手续费。**

- 股票：通常按成交额的万分之几
- 期货：通常按固定金额每手
- 外汇：通常包含在点差里

### 点差（Spread）

**点差 = 买价（bid）和卖价（ask）的差。**

- 你买入的价格 = ask（较高）
- 你卖出的价格 = bid（较低）
- 一买一卖，你就亏了一个点差

### 计算总成本

```
单笔交易总成本 = 佣金 + 滑点 + 点差
```

**示例：**
- 你做一笔 1 万美金的交易
- 佣金 = 5 美金（万分之五）
- 滑点 = 10 美金（0.1%）
- 点差 = 5 美金（0.05%）
- 总成本 = 20 美金 = 0.2%

**如果你每天交易一次，一年就是 50% 的成本！**

## 市场冲击成本

### 什么是市场冲击

**你下大单的时候，会推动价格朝你不利的方向走。**

- 你买 1000 万的股票
- 你吃完了卖盘的所有挂单
- 价格被你推高了
- 你的平均买入价高于最初的价格

### 市场冲击的影响因素

1. **订单大小**：你买得越多，冲击越大
2. **当时流动性**：流动性差的时候，冲击大
3. **交易速度**：你下单越快，冲击越大
4. **品种波动性**：波动大的品种，冲击大

### 估算公式

```
冲击成本 ≈ σ × √(Q / ADV)
```

- σ：日波动率
- Q：你的订单量
- ADV：日均成交量

**解读：你的订单量占日均成交量的比例越大，冲击越大。**

### 经验法则

- 订单 < 1% ADV：冲击很小，可以忽略
- 订单 1-5% ADV：有一定冲击，需要建模
- 订单 > 5% ADV：冲击很大，需要拆单算法

## 流动性约束

### 什么是流动性约束

**回测里你假设你想买多少就能买多少，但实盘不是这样。**

- 你想在最低价买入 1000 手
- 但那个价位上只有 50 手挂单
- 你只能买到 50 手，剩下的吃了更高的价格

### 常见约束

1. **成交量约束**：单笔交易不能超过当时成交量的 X%（比如 10%）
2. **持仓约束**：你的持仓不能超过总流通盘的 X%
3. **时间约束**：你不能在开盘前 5 分钟和收盘后 5 分钟交易（流动性差）

### 回测里怎么处理

```python
# 伪代码
max_trade_volume = bar.volume * 0.1  # 最多吃当时成交量的10%
if order_size > max_trade_volume:
    order_size = max_trade_volume  # 截断
```

## 跳空与缺口

### 什么是跳空

**K线图上相邻两根K线之间的价格不连续。**

- 昨天收盘价 100
- 今天开盘价 105
- 中间 100-105 是缺口，你没有机会在那个价格成交

### 回测里的常见错误

❌ 错误：回测假设价格是连续的，止损设在 99 就一定能在 99 成交
✅ 正确：如果跳空低开在 95，你的止损只能在 95 成交

### 跳空的风险

- 你的止损在 100
- 晚上出了大利空
- 第二天开盘直接跳空到 90
- 你以为亏 1%，实际亏了 10%

**这就是为什么止损不是万能的——极端情况下，止损也会跳空。**

## 回测验证体系

### Walk-Forward 分析

**什么是 Walk-Forward？**

不是一次性把数据分成训练集和测试集，而是滚动：
1. 用 2010-2015 训练，2016 测试
2. 用 2011-2016 训练，2017 测试
3. 用 2012-2017 训练，2018 测试
4. ...

**为什么比单次样本外好？**
- 更贴近实盘：你就是这样不断用最新数据更新模型的
- 更可靠：多个测试期的结果比一个测试期更可信

### 蒙特卡洛模拟

**什么是蒙特卡洛？**

把你策略的历史交易顺序打乱，重新算收益曲线。

**为什么要做？**
- 你历史上的交易顺序可能刚好是"好的顺序"
- 打乱后看看最坏情况是怎样的
- 评估策略的鲁棒性

### 参数敏感性分析

**什么是参数敏感性？**

把参数微调一下，看看性能变化大不大。

- 如果参数从 20 改成 21，Sharpe 从 1.5 掉到 0.5 → 太敏感了，过拟合
- 如果参数从 20 改成 25，Sharpe 还是 1.4 → 很稳健

## 顶级机构怎么做

### Renaissance / Two Sigma
- 极精细的执行成本模型
- 每笔订单的冲击成本都实时估算
- 拆单算法（VWAP/TWAP/POV）最小化冲击

### 高频做市商（Jane Street / Optiver）
- 点差和库存风险就是他们的收入来源
- 他们的利润模型本质上就是执行成本模型

### 共同原则
- **执行成本不是小问题，是决定生死的大问题**
- **回测越真实，实盘差距越小**
- **先假设回测是假的，再一步步证明它是真的**
