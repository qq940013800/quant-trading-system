> 波动率不是风险，永久性资本损失才是。风险模型的目标不是精确预测损失，而是知道最坏情况可能有多坏。

## 风险的正确定义

### 错误的风险观

- ❌ 波动率 = 风险
- ❌ 最大回撤 = 风险
- ❌ Beta = 风险

### 正确的风险观

**风险 = 永久性资本损失的概率和幅度。**

波动率只是风险的一个观测指标，不是风险本身。

### 关键推论

1. **尾部风险才是真风险**——日常波动可以忍，黑天鹅不能忍
2. **流动性风险常被低估**——你以为有止损，真到危机时跑不掉
3. **杠杆是风险放大器**——不创造Alpha，只放大已有错误
4. **相关性风险**——平时不相关的资产，危机时一起跌

## VaR与CVaR

### VaR（风险价值）

**定义：** 在一定置信水平下，投资组合在未来特定时间内的最大可能损失。

**例子：**
- 95% VaR = 100万
- 意思是：95%的概率，一天内亏损不超过100万
- 反过来：5%的概率，亏损超过100万

### VaR的致命缺陷

VaR只告诉你"最坏5%的门槛在哪"，但不告诉你**超过门槛之后会亏多少**。

**例子：**
- 策略A：95% VaR = 100万，超过VaR后平均亏120万
- 策略B：95% VaR = 100万，超过VaR后平均亏500万

VaR一样，但B的尾部风险大得多。

### CVaR（条件风险价值）

CVaR = 超过VaR后的平均损失。

**CVaR才是真正的尾部风险度量。**

| 指标 | 回答的问题 |
|------|-----------|
| VaR | 最坏5%的门槛在哪？ |
| CVaR | 最坏5%里平均亏多少？ |

## 尾部风险

### 为什么尾部风险最重要

- 大部分时间策略表现很好，你以为很安全
- 一次尾部事件就能毁掉几年的收益
- 诺贝尔奖得主的LTCM就是死于尾部风险

### 厚尾分布

金融收益率不是正态分布——尾部比正态分布厚得多。

**正态分布假设下，2008年那种事件1000年才发生一次。但现实是几十年就来一次。**

### 尾部风险来源

1. **流动性枯竭**——大家都想跑，没人接盘
2. **相关性飙升**——平时不相关的资产一起跌
3. **杠杆连锁反应**——一个基金爆仓→被迫平仓→价格跌→下一个爆仓
4. **跳空缺口**——隔夜风险，止损单没用

## 压力测试

### 为什么要做压力测试

VaR基于历史数据，但黑天鹅是历史上没发生过的。

压力测试 = 主动想象极端情况，看看系统会怎样。

### 历史情景压力测试

| 情景 | 描述 | 影响 |
|------|------|------|
| 2008金融危机 | 次贷危机，全球股市跌50% | 所有风险资产一起跌 |
| 2020疫情 | 新冠疫情，熔断多次 | 流动性瞬间枯竭 |
| 1987黑色星期一 | 一天跌20% | 程序化交易连锁反应 |
| 2015瑞郎黑天鹅 | 瑞士央行取消汇率下限 | 单日涨30%，无数爆仓 |

### 假设情景压力测试

不基于历史，自己设计极端情况：

1. **波动率飙升**：ATR从2涨到6（3倍）
2. **相关性趋近于1**：所有策略一起亏
3. **流动性消失**：滑点从1个点变成20个点
4. **跳空缺口**：开盘直接跳过止损位

### 压力测试结果怎么用

不是为了"通过压力测试"，而是：
1. 知道最坏情况会亏多少
2. 调整仓位，让最坏情况你能承受
3. 提前准备应对方案

## 蒙特卡洛模拟

### 原理

用随机数生成成千上万种可能的未来，看看你的策略在各种情况下表现如何。

### 步骤

1. 估计收益率的分布（均值、波动率、相关性）
2. 随机生成10000条可能的价格路径
3. 对每条路径跑策略
4. 统计结果：分布、最差5%、最好5%

### 输出什么

- 最大回撤的分布（不是历史上的最大回撤，而是可能的最大回撤）
- 爆仓概率（亏到0的概率）
- 不同波动率假设下的表现

### 关键注意事项

1. **不能用正态分布假设**——要用厚尾分布
2. **要考虑波动率聚集**——大波动后面跟着大波动
3. **要考虑时变相关性**——危机时相关性会变

## 风险预算

### 核心理念

不是"这个策略能赚多少"，而是"这个策略最多能亏多少，我愿意给它多少风险额度"。

### 风险预算分配

```
总风险预算 = 组合最大可承受回撤（比如20%）

分配给每个策略：
    策略A：风险预算 8%
    策略B：风险预算 6%
    策略C：风险预算 4%
    策略D：风险预算 2%
```

每个策略的仓位大小，由它的风险预算决定：

```
仓位 = 风险预算 / 策略的波动率
```

### 与资金分配的区别

- 资金分配：按钱分（50%给A，50%给B）
- 风险预算：按风险分（A贡献8%的风险，B贡献6%的风险）

风险预算更合理——因为波动大的策略，同样的钱风险大得多。

## 常见陷阱

### 1. 用波动率代替风险

波动率高的策略不一定风险大——如果它只会向上波动。

真正的风险是下行的永久性损失。

### 2. 相信VaR就安全了

VaR只是门槛，门槛后面的尾部才是真危险。

### 3. 压力测试用历史数据

历史上发生过的最坏情况，不一定是未来的最坏情况。

### 4. 忽略流动性风险

回测里假设能按收盘价成交，但实盘极端情况下你根本跑不掉。

### 5. 忽略相关性变化

平时相关性0.3，危机时变成0.9。
