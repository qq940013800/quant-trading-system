# 第一性原理与顶尖思维模型（可执行版）

> 本篇不重复 L1 的教科书内容（`skills/quant-trading-expert/references/first-principles.md`、
> `mental-models.md`），只做一件事：**把原理与思维模型翻译成系统里可执行的判断规则、代码断言和检查清单**。
>
> 阅读前提：承认三个事实——(1) 市场是自适应的对抗系统；(2) 我们无法预测，只能管理概率与风险；
> (3) 长期存活比单次正确重要一个数量级。

---

## 0. BLUF（先给结论）

1. **收益的唯一来源是"别人为什么愿意把钱输给你"**。说不清这个理由的策略，长期期望必然 ≤ 0（含成本）。
2. **复利发生在几何空间，不在算术空间**。最大化 `E[log(1+r)]`，不是最大化 `E[r]`；这直接推出分数 Kelly 与回撤控制。
3. **生存是硬约束，不是优化目标**。爆仓一次，之前所有正期望都归零（路径依赖 / 非遍历性）。
4. **过拟合的本质是"选择行为"**，不是模型复杂度。试验次数必须计入，样本外是唯一裁判。
5. **成本是确定性的，Alpha 是不确定性的**。先用成本把策略杀一遍，再谈预测能力。
6. **逆向思维优先于正向优化**：先列出所有会死的方式，逐条加控制，再考虑怎么赚。
7. **可复制的是流程（研究→验证→风控→复盘），不可复制的是收益率**；把流程做成系统，才有复利。
8. **一切结论都要能被证伪**：写下"什么证据出现我就认错"，否则不是知识，是信仰。

## 1. 公理层：交易系统的第一性原理

### 1.1 收益恒等式

```
净收益 = 预测优势 × 风险承担 × 执行效率 − 交易成本 − 融资成本
```

四项中任意一项为 0 或为负，系统长期不赚钱。**推论**：
- 没有预测优势时，承担风险只是买彩票（负和游戏扣成本后为负）；
- 有预测优势但执行差，优势会被滑点/冲击吃光（小容量策略的常见死法）；
- 成本是**确定性支出**，必须在下单前扣掉，不能"回测后再看"。

### 1.2 Alpha 的四种来源（以及它们为什么会消失）

| 来源 | 机制 | 谁在付钱 | 衰减原因 | 我们的对应 |
|---|---|---|---|---|
| 信息优势 | 更快/更全/更干净的数据 | 信息滞后方 | 数据民主化、传播加速 | 另类数据、事件驱动 |
| 行为偏差 | 恐惧/贪婪/锚定/处置效应 | 非理性交易者 | 市场学习、机构化 | 趋势/反转、情绪极端 |
| 统计优势 | 大量弱信号的横截面规律 | 噪声交易者 | 拥挤、被套利 | 弱信号工厂、ML 集成 |
| 结构红利 | 流动性提供、风险转移、监管/制度约束 | 需要即时性/转移风险的人 | 竞争加剧、制度变化 | 做市、基差、Carry |

**判断规则（写进策略准入清单）**：
- [ ] 这个策略赚的是上表哪一类钱？
- [ ] 付钱方为什么持续愿意付？（不是"因为市场无效"这种同义反复）
- [ ] 这个优势的容量上限大概多少？我们规模是否在容量内？
- [ ] 什么事件会让它消失？（列出可观测的先行指标）

### 1.3 非遍历性：为什么"期望为正"还不够

财富是乘性的：`W_T = W_0 · Π(1 + r_t)`。时间平均增长率：

```
g = E[log(1 + r)] ≈ E[r] − Var(r)/2      （小 r 近似）
```

- 算术期望相同的两个策略，波动大的那个**长期增长率更低**（波动拖累）；
- 一次 −100% 让路径终止，之后的正期望与你无关 → **破产是不可逆吸收态**；
- 因此目标函数是 `max E[log W]`，约束是 `P(ruin) < ε`。

**可执行规则**：
1. 单笔风险预算 ≤ 账户权益的固定小比例（本仓库默认 1%，见 `core/risk/sizing.py`）；
2. 用分数 Kelly（1/4–1/2），因为 Kelly 假设参数已知，而我们的 edge 是估计值；
3. 任何"加倍下注/摊平亏损"的规则一律禁止（马丁格尔在有限资金下必破产）。

### 1.4 凯利公式与它的现实修正

```
f* = edge / odds = (p·b − q) / b        （b=盈亏比，p=胜率，q=1−p）
```

现实修正（全部写进 `core/risk/sizing.py` 的注释与测试）：
- p、b 是估计值，估计误差大 → 用 `f = c·f*`，c ∈ [0.25, 0.5]；
- 多策略相关时，Kelly 需用协方差矩阵求解，且相关性上升时总杠杆必须下降；
- Kelly 的最优性是**对数效用**下的，若效用/约束不同（回撤上限、赎回线），先满足约束。

### 1.5 成本与容量

```
单位成本 ≈ 佣金 + 半价差 + 滑点 + 市场冲击
冲击 ≈ k · σ · sqrt(Q / ADV)          （平方根冲击模型，k 为经验系数）
```

**推论**：换手率越高的策略，对成本越敏感；容量由 `ADV` 与可接受冲击决定。
回测必须用**保守成本假设**（设计文档要求：分时段点差 + 滑点 + 佣金，禁止零成本）。

### 1.6 自适应市场：Red Queen 效应

市场参与者会学习。任何公开、简单、稳定的规律都会被套利掉。**推论**：
- 策略有生命周期：研发 → 上线 → 衰减 → 退役；
- 必须监控"同一信号的拥挤度"和"实盘 vs 回测的偏离"；
- 不存在"设置后不管"的圣杯；系统必须能**发现自己在失效**。

## 2. 思维模型 → 交易决策规则

| 思维模型 | 原始含义 | 在交易系统中的可执行版本 | 本仓库落点 |
|---|---|---|---|
| 第一性原理 | 拆到不可再分的事实再重建 | 每个策略先回答"赚谁的钱、为什么持续" | 策略准入清单 / `registry.yaml` hypothesis 字段 |
| 逆向思维（Via Negativa） | 先想怎么死，避开它 | 先建"死法清单"与控制项，再谈收益 | `docs/ANTI_FRAGILE.md`、`06_failures_and_lessons.md` |
| 二阶思维 | 想后果的后果 | 策略拥挤 → 相关性上升 → 尾部同时亏损 | 拥挤度监控、压力测试 |
| 基础比率 | 先看同类事件的基准概率 | 新策略先验：多数主动策略跑不赢基准 | 策略上线门槛、Deflated Sharpe |
| 安全边际 | 留出错空间 | 成本假设上浮、容量打折、仓位打折 | 成本模型 ×1.5 压力测试 |
| 杠铃策略 | 极保守 + 小比例极激进 | 大部分资金低风险，小部分试错新策略 | 资金分配器、策略孵化仓 |
| 可选性（Optionality） | 小成本买未来选择权 | 用有限风险试新数据/新策略，保留退出权 | A/B 测试、影子模式 |
| 能力圈 | 只做看得懂的 | 数据/执行/标的超出理解范围就不做 | 策略准入的"数据可得性"检查 |
| 奥卡姆剃刀 | 简单优先 | 能用规则解释就不用复杂模型；参数越少越好 | 模型选择：先基线后 GBM |
| 林迪效应 | 存在越久越可能继续存在 | 优先复用久经考验的机制（止损、分散、对账） | 平台组件复用 |
| 古德哈特定律 | 指标一旦成为目标就失效 | 不用单一指标（Sharpe）做唯一目标；用多指标+样本外 | 绩效评估多指标 |
| 幸存者偏差 | 只看到活下来的 | 策略池统计必须包含已退役/失败策略 | registry trials_N、策略生命周期 |
| 地图不是疆域 | 模型不是现实 | 回测是地图；实盘偏差是常态 | 实盘 vs 回测对账、滑点回填 |
| 反脆弱 | 从波动中受益 | 控制凸性：小亏多次、大赚少数；避免负凸性 | 止损/止盈结构、尾部对冲 |
| 遍历性 | 时间平均 ≠ 集合平均 | 先保命，再谈期望 | 风险预算、熔断、回撤线 |
| 贝叶斯更新 | 用新证据更新信念 | 策略健康度随实盘证据更新，不因短期盈亏翻案 | 健康度监控、漂移检测 |
| OODA 循环 | 观察-定向-决策-行动 | 监控 → 归因 → 调仓/退役 → 验证，闭环要快 | 监控告警 + 复盘流程 |
| 系统思维 | 看反馈回路 | 风控收紧会改变收益分布；考核会改变行为 | 变更管理、A/B 实验 |
| 汉隆剃刀 | 别把错误当恶意 | 对账差异先查 bug，不假设对方作弊 | 故障排查流程 |
| 帕累托 | 80/20 | 20% 的模块（风控/执行/数据）决定 80% 的生存概率 | 优先级排序 |

## 3. 三张可执行清单

### 3.1 策略准入清单（任一不过 → 不上线）

- [ ] Alpha 来源可解释，且能说清"谁在付钱"；
- [ ] 数据因果性通过（`tests/test_features_causal.py` 类断言）；
- [ ] 样本外/CPCV/PBO/Deflated Sharpe 全部达标，且 `trials_N` 已登记（含失败试验）；
- [ ] 成本按保守假设（×1.5）后仍为正期望；
- [ ] 容量估算 ≥ 目标资金 × 安全系数；
- [ ] 极端情景（跳空、流动性枯竭、相关性→1）下最大回撤可承受；
- [ ] 有明确的失效判据与退役流程；
- [ ] 有监控指标（IC、胜率、盈亏比、滑点、回测偏离）。

### 3.2 交易前检查（每次下单前）

- [ ] 信号在**已收盘 bar** 上产生（禁止 intra-bar）；
- [ ] 仓位 = 风险预算 / 止损距离，且不超过单品种/单策略/组合限额；
- [ ] 止损已设置且方向正确（只向盈利方向移动）；
- [ ] 账户状态正常（未熔断、未达回撤线、数据未过期）；
- [ ] 订单参数通过 `SymbolInfo*` 获取（不硬编码点值/手数）；
- [ ] 幂等键唯一，重试安全。

### 3.3 复盘清单（每笔/每日/每周）

- [ ] 这笔交易是否符合策略定义？（偏离即记为执行错误）
- [ ] 滑点 vs 预期？成本是否超预算？
- [ ] 亏损是"策略内正常亏损"还是"策略失效信号"？
- [ ] 是否有可复用的新知识？（写入 `SUCCESS_PLAYBOOK` / `ERROR_LOG`）
- [ ] 系统层面：数据、执行、监控是否出现异常？

## 4. 常见认知陷阱（按危害排序）

| 陷阱 | 表现 | 解药 |
|---|---|---|
| 过拟合 | 回测漂亮、实盘亏损 | 试验计数 + 样本外 + PBO/DSR + 规则冻结 |
| 前视偏差 | 用了未来信息而不自知 | 因果断言、available_at 列、单测守卫 |
| 幸存者偏差 | 只统计活下来的策略/交易员 | 全量记录（含退役）、基础比率 |
| 叙事谬误 | 用故事解释随机结果 | 先做统计检验，再讲故事 |
| 杠杆幻觉 | 用杠杆放大"稳定"收益 | 压力测试、相关性突变、强平线 |
| 控制错觉 | 频繁调参/干预 | 决策规则冻结、变更审计 |
| 损失厌恶 | 死扛亏损、过早止盈 | 规则化止损/止盈，禁止手动干预 |
| 近期偏差 | 用最近行情外推 | regime 识别、长样本、多市场验证 |
| 确认偏差 | 只找支持自己的证据 | 预先写证伪条件、红队评审 |
| 复杂性偏好 | 模型越复杂越安心 | 奥卡姆剃刀、基线对比、可解释性 |
