# QuantDinger AI/ML 增强量化交易系统

> 基于第一性原理和全球顶级量化机构最佳实践构建的企业级AI/ML增强量化交易系统

## 系统概述

QuantDinger是一个AI/ML增强的全栈量化交易系统，整合了信号生成、组合管理、风险控制、自动执行和绩效分析的完整闭环。系统设计对标Jane Street、Citadel、Renaissance、Two Sigma等全球顶级量化机构的最佳实践。

### 核心理念

```
数据输入 → 信号生成 → 组合构建 → 订单执行 → 风控监控 → 绩效分析
     ↑                                                        ↓
     └────────────────── 反馈优化 ←─────────────────────────────┘
```

### 三大不可协商的不变量

1. **因果单向** — 任何计算只使用 `available_at <= bar.close` 的数据，杜绝前视偏差
2. **决策可审计** — 每笔接受/拒绝都能还原各层输入与判断，完整审计日志
3. **阈值来自分布** — 不由绩效网格搜索产生，基于统计分布估计

## 核心特性

### AI/ML 增强

- **特征工程**：自动特征生成、特征选择、特征重要性分析
- **模型训练**：支持XGBoost、LightGBM、LSTM、Transformer等多种模型
- **Meta-Labeling**：二级模型优化择时，提升胜率
- **漂移监控**：数据漂移、概念漂移检测与告警
- **模型注册**：模型版本管理、A/B测试、灰度发布

### 风控体系

- **事前风控**：下单前校验仓位、限额、相关性
- **事中风控**：实时监控持仓、盈亏、风险敞口
- **事后风控**：交易后分析、归因、复盘、策略健康度
- **多层级风险**：单笔交易风险、策略级风险、组合级风险、账户级风险

### 知识沉淀系统

- **决策审计**：每笔交易完整决策链路记录
- **交易日志**：自动记录每笔交易与盈亏
- **故障知识库**：自动捕获故障，沉淀解决方案
- **实验管理**：策略实验自动记录与对比
- **复盘机制**：定期自动触发复盘，生成改进建议

## 技术栈

### 前端
- **框架**：Vue 3 + TypeScript
- **UI库**：Ant Design Vue
- **图表**：ECharts / TradingView Lightweight Charts
- **状态管理**：Pinia
- **构建工具**：Vite

### 后端
- **框架**：Python FastAPI
- **任务队列**：Celery + Redis
- **调度器**：Celery Beat
- **ORM**：SQLAlchemy
- **实时通信**：WebSocket

### 数据层
- **关系数据库**：PostgreSQL 16
- **缓存**：Redis
- **时序数据**：PostgreSQL BRIN索引
- **对象存储**：本地文件 / MinIO

### 部署
- **容器化**：Docker + Docker Compose
- **反向代理**：Nginx
- **监控**：Grafana + Prometheus
- **日志**：集中式日志管理

## 快速开始

### 环境要求

- Docker 20+
- Docker Compose 2+
- 4GB+ 内存

### 一键部署

```bash
# 1. 克隆仓库
git clone https://gitee.com/taoaiguo/quant-trading-system.git
cd quant-trading-system

# 2. 配置环境变量
cp backend_api_python/env.example backend_api_python/.env
# 编辑 .env 设置 SECRET_KEY 和数据库密码

# 3. 启动服务
docker-compose up -d

# 4. 访问系统
# Web前端: http://localhost:8888
# API文档: http://localhost:5000/docs
```
