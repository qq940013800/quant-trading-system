# 方案 2：风险预算模块口径选型——【资金名义占比】vs【波动率风险贡献】

> 状态：**待评审草稿**，不含生产代码。
> 背景：风险预算面板当前为四条静态演示（突破 35% / 均值回归 28% / 趋势跟踪 22% / ML 预测 15%），名称与真实策略不符。后端**未提供**策略级风险贡献（risk contribution）；现有 `initial_capital` 只能算名义资金占比。两套口径含义不同，必须先拍板采用哪一套（或并列展示并标注口径）。

## 1. 两种口径定义

### 口径 A：资金名义占比（Nominal Capital Weight）
- **定义**：策略分配/占用的名义资金占组合总资金的比例。
  - 公式：`w_i = 初始资金_i / Σ 初始资金_j`（或按当前权益、按持仓名义市值）。
- **数据可得性**：✅ 现有 `/api/strategies` 有 `initial_capital`；实测 5 条各 1000，名义占比各 20%。
- **反映什么**：钱分给了谁；**不反映**谁对组合波动/回撤的真实贡献。
- **局限**：高波动策略与低波动策略各占 20% 资金，对组合风险的贡献差异很大；资金占比 ≠ 风险占比。

### 口径 B：波动率风险贡献（Volatility Risk Contribution / Risk Parity）
- **定义**：在给定协方差矩阵下，各策略边际风险贡献（MRC）或成分风险贡献（RC）占组合总风险的比例。
  - 成分风险贡献：`RC_i = w_i · (Σw)_i / (wᵀΣw)`，`Σ RC_i = 1`。
- **数据可得性**：❌ 后端当前无策略收益协方差/波动率序列；需先有日级（或周级）策略收益序列，估计协方差矩阵。
- **反映什么**：谁真正驱动了组合波动与回撤；风险平价目标是让各策略风险贡献趋于均衡。
- **局限**：依赖历史协方差估计，样本不足/结构突变时不稳；相关性在危机时趋同，风险贡献会失真；计算与维护成本高。

## 2. 对比表

| 维度 | A 资金名义占比 | B 波动率风险贡献 |
|---|---|---|
| 含义 | 资金分配比例 | 风险贡献比例 |
| 所需数据 | 初始资金/权益/持仓名义市值 | 策略收益序列 + 协方差矩阵 |
| 后端现状 | 已有 `initial_capital`，可现算 | 缺收益序列与协方差，需新建 |
| 计算复杂度 | 低（一次除法） | 中高（收益序列→协方差→边际/成分贡献） |
| 稳定性 | 高 | 受样本长度、估计窗口、相关性突变影响 |
| 机构对标 | 常见于资金分配/仓位面板 | 风险平价、风险预算模型核心指标 |
| 误用风险 | 易被误读为"风险占比" | 估计不稳时误导性更强 |
| 落地优先级 | 可先落地，必须显式标注"资金占比" | 待收益序列与协方差基建就绪后落地 |

## 3. 选型建议（供评审）

### 阶段 1（当前可落地）：口径 A + 明确标注
- 面板标题/列名明确写"**资金名义占比**"，不使用"风险预算/风险贡献"字样，避免口径混淆。
- 数值由 `initial_capital`（或当前权益）现算；缺失资金的策略占比 `--`。
- 副标注："本面板为资金分配占比，非波动率风险贡献；风险贡献待收益序列与协方差基建就绪后补充。"

### 阶段 2（后续）：口径 B 风险贡献
- 前置依赖：策略日级收益序列落库（可由权益曲线/成交记录派生）；协方差估计窗口与收缩方法（如 Ledoit-Wolf）确定。
- 输出边际风险贡献 MRC 与成分风险贡献 RC；面板并列展示"资金占比 / 风险贡献"两列，便于看出错配。

### 不建议
- 在无协方差数据时，用资金占比冒充"风险预算/风险贡献"展示给用户。
- 直接按波动率倒数拍权重而不说明假设（无收益序列时波动率无从估计）。

## 4. 未决项（评审拍板）

- **C1 占比基数**：名义占比按初始资金、当前权益，还是持仓名义市值？三者口径不同。
- **C2 并列还是单选**：阶段 1 是否预留第二列位置，后续接入风险贡献后并列展示。
- **C3 协方差估计窗口**：风险贡献采用 20/60/252 日哪个窗口；是否做相关性收缩。
- **C4 空仓/未运行策略**：无持仓、未运行策略在风险预算面板如何列示（占比 0 还是 `--`）。

## 5. 验收标准（阶段 1）

1. 面板口径标签为"资金名义占比"，不出现未实现的"风险贡献"指标名。
2. 占比由真实资金字段现算，缺失字段渲染 `--`，不保留静态演示百分比。
3. 不修改仓位管理、下单/平仓、资金计算逻辑；占比为只读派生展示。

## 6. 风险与未验证

- 风险贡献（口径 B）在当前数据基建下无法计算，本方案不预填任何风险贡献数值。
- 协方差/风险平价相关计算的稳定性需在有足够样本后回测验证；当前为方案层面结论。
